In Python, **`random.seed(123)`** initializes the pseudo-random number generator with a specific starting value (a "seed").

### What it does in Python

Computers cannot generate truly random numbers; instead, they use mathematical formulas to generate **pseudo-random**
sequences.

- By default, Python picks a seed based on the current system time.
- Setting a specific seed (like `123`) forces the generator to start from a fixed point. This means **every time you run your
  code, you will get the exact same sequence of random numbers**. This is extremely useful for debugging, testing, or
  ensuring reproducibility in machine learning and data science.

---

### How to do it in TypeScript / JavaScript

JavaScript's built-in `Math.random()` **does not support seeding**. To get reproducible random numbers in TypeScript, you
have two main options: using a lightweight library or writing a simple custom generator.

#### Option 1: Using a library (Recommended)

The most robust way is to use a popular npm package like `seedrandom`.

1. Install the package:

```bash
npm install seedrandom
npm install --save-dev @types/seedrandom

```

2. Use it in your TypeScript code:

```typescript
import seedrandom from "seedrandom";

// Initialize the seeded random generator
const rng = seedrandom("123"); // Can take a string or number

// Generates a random number between 0 and 1 (like Math.random())
console.log(rng());
console.log(rng());
```

#### Option 2: Custom Linear Congruential Generator (Zero Dependencies)

If you don't want to install external packages, you can implement a simple PRNG algorithm (like an LCG) in a few lines of
TypeScript:

```typescript
function createSeededRandom(seed: number) {
  let state = seed;
  return function () {
    // Numerical Recipes LCG constants
    state = (state * 1664525 + 1013904223) % 4294967296;
    return state / 4294967296; // Returns a float between 0 and 1
  };
}

// Equivalent to random.seed(123)
const rng = createSeededRandom(123);

console.log(rng()); // Always produces the same value for seed 123
console.log(rng()); // Next value in the reproducible sequence
```
