In Python, the **vector product (cross product)** of two vectors is calculated using NumPy's `np.cross()` function.

The cross product produces a new vector that is perpendicular to both input vectors.

## 1\. Mathematical example

Let's define two 3D vectors:

$$
A =
\begin{bmatrix}
1\\
2\\
3
\end{bmatrix}
\qquad
B =
\begin{bmatrix}
4\\
5\\
6
\end{bmatrix}
$$

The cross product is:

$$
A \times B =
\begin{bmatrix}
A_yB_z-A_zB_y\\
A_zB_x-A_xB_z\\
A_xB_y-A_yB_x
\end{bmatrix}
$$

Substituting our values:

$$
A \times B =
\begin{bmatrix}
2\cdot6-3\cdot5\\
3\cdot4-1\cdot6\\
1\cdot5-2\cdot4
\end{bmatrix}
$$

Result:

$$
\boxed{
A \times B =
\begin{bmatrix}
-3\\
6\\
-3
\end{bmatrix}
}
$$

## 2\. Python implementation using NumPy

python

```python
import numpy as np

A = np.array([1, 2, 3])
B = np.array([4, 5, 6])

# Cross product
C = np.cross(A, B)

print(C)
```

Output:

text

```text
[-3  6 -3]
```

That's it\! NumPy calculates the cross product automatically.

## 3\. Verify that the result is perpendicular

An important property of the cross product is that the resulting vector is perpendicular to both original vectors.

We can verify this using the dot product.

python

```python
import numpy as np

A = np.array([1, 2, 3])
B = np.array([4, 5, 6])

C = np.cross(A, B)

print("Cross product:", C)

print("A dot C:", np.dot(A, C))
print("B dot C:", np.dot(B, C))
```

Output:

text

```text
Cross product: [-3  6 -3]

A dot C: 0
B dot C: 0
```

Both dot products equal zero, confirming that the resulting vector is perpendicular to the original vectors.

## 4\. Cross product vs. dot product

These are two different vector multiplication operations.

| Feature     | Dot product         | Cross product                 |
| ----------- | ------------------- | ----------------------------- |
| NumPy       | `np.dot(A, B)`      | `np.cross(A, B)`              |
| Result      | Scalar (number)     | Vector                        |
| Dimensions  | Same-length vectors | 3D vectors                    |
| Geometry    | Measures alignment  | Produces perpendicular vector |
| Commutative | Yes                 | No                            |

For example:

python

```python
import numpy as np

A = np.array([1, 2, 3])
B = np.array([4, 5, 6])

# Dot product
print(np.dot(A, B))
# 32

# Cross product
print(np.cross(A, B))
# [-3  6 -3]
```

**Important:** The cross product is anti-commutative:

$$
A \times B = -(B \times A)
$$

Therefore:

python

```python
print(np.cross(A, B))
# [-3  6 -3]

print(np.cross(B, A))
# [ 3 -6  3]
```

## 5\. Practical application: Calculating area

The magnitude (length) of the cross product gives the area of the parallelogram formed by two vectors.

$$
Area = |A \times B|
$$

Python:

python

```python
import numpy as np

A = np.array([1, 2, 3])
B = np.array([4, 5, 6])

C = np.cross(A, B)

area = np.linalg.norm(C)

print(area)
```

Output:

text

```text
7.3484692283495345
```

The area of the triangle formed by these vectors would be half that value:

$$
Area_{triangle} = \frac{|A \times B|}{2}
$$
