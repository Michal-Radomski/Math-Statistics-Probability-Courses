The main difference between **linear algebra** and **non-linear algebra** is how variables interact with each other,
particularly whether equations contain powers, products, or other non-linear functions of variables.

Let's look at practical examples using mathematics and Python.

# 1\. Linear algebra

Linear algebra deals with linear equations, vectors, matrices, and linear transformations.

A linear equation has variables with a maximum power of 1. Variables cannot be multiplied by other variables.

### Example 1: Linear equation

Mathematical representation:

$$
2x + 3y = 8
$$

Another equation:

$$
4x + y = 6
$$

Together:

$$
\begin{cases}
2x + 3y = 8\\
4x + y = 6
\end{cases}
$$

Python implementation:

python

```python
import numpy as np

# Coefficient matrix
A = np.array([
    [2, 3],
    [4, 1]
])

# Results
b = np.array([8, 6])

# Solve the system
solution = np.linalg.solve(A, b)

print(solution)

# [1. 2.]
```

The solution is:

$$
x=1,\quad y=2
$$

### Example 2: Matrix multiplication

python

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

B = np.array([
    [5, 6],
    [7, 8]
])

C = A @ B

print(C)
```

Result:

text

```text
[[19 22]
 [43 50]]
```

### Example 3: Linear transformation

Imagine rotating or scaling a vector.

python

```python
import numpy as np

vector = np.array([2, 3])

# Scaling matrix
M = np.array([
    [2, 0],
    [0, 2]
])

result = M @ vector

print(result)
# [4 6]
```

This is a linear transformation.

# 2\. Non-linear algebra

Non-linear algebra deals with equations where variables can have powers greater than 1, multiply each other, or appear in
functions such as sine, cosine, or exponentials.

### Example 1: Quadratic equation

Mathematical representation:

$$
x^2 + 2x - 8 = 0
$$

Python:

python

```python
import numpy as np

# Coefficients: x² + 2x - 8
coefficients = [1, 2, -8]

solutions = np.roots(coefficients)

print(solutions)

# [-4.  2.]
```

Solutions:

$$
x=-4,\quad x=2
$$

### Example 2: Non-linear system of equations

Consider:

$$
\begin{cases}
x^2 + y^2 = 25\\
x \cdot y = 12
\end{cases}
$$

Python implementation:

python

```python
from scipy.optimize import fsolve

def equations(variables):

    x, y = variables

    eq1 = x**2 + y**2 - 25
    eq2 = x * y - 12

    return [eq1, eq2]


solution = fsolve(equations, [3, 4])

print(solution)
```

One possible solution:

text

```text
[3. 4.]
```

### Example 3: Exponential function

Mathematical representation:

$$
y = e^x
$$

Python:

python

```python
import numpy as np

x = np.array([0, 1, 2, 3])

y = np.exp(x)

print(y)
```

Result:

text

```text
[ 1.          2.71828183  7.3890561  20.08553692]
```

### Example 4: Non-linear transformation

python

```python
import numpy as np

x = np.array([1, 2, 3, 4])

# Non-linear transformation
y = x**2

print(y)

# [ 1  4  9 16]
```

# 3\. Linear vs. non-linear comparison

| Feature          | Linear algebra         | Non-linear algebra                    |
| ---------------- | ---------------------- | ------------------------------------- |
| Variables        | First power            | Can have higher powers                |
| Multiplication   | No variable × variable | Variable × variable allowed           |
| Equations        | Linear                 | Non-linear                            |
| Matrices         | Fundamental tool       | Can be used, but not sufficient alone |
| Solutions        | Often straightforward  | Can be more complicated               |
| Optimization     | Linear optimization    | Non-linear optimization               |
| Python libraries | NumPy, SciPy           | SciPy, SymPy                          |

# 5\. Where are they used in practice?

Both are extremely important in programming, engineering, physics, and machine learning.

| Application       | Linear algebra             | Non-linear algebra                  |
| ----------------- | -------------------------- | ----------------------------------- |
| Computer graphics | Transformations, rotations | Perspective projection              |
| Machine learning  | Linear regression          | Neural networks                     |
| Physics           | Linear systems             | Fluid dynamics                      |
| Robotics          | Coordinate transformations | Robot kinematics                    |
| Data science      | PCA                        | Non-linear dimensionality reduction |
| Optimization      | Linear programming         | Non-linear optimization             |

## 6\. Bonus: Combining both in Python

You can combine linear and non-linear operations.

For example, suppose you have a vector and want to apply a matrix transformation, followed by a non-linear function.

python

```python
import numpy as np

# Input vector
x = np.array([1, 2, 3])

# Linear transformation
W = np.array([
    [1, 2, 0],
    [0, 1, 1],
    [2, 0, 1]
])

linear_result = W @ x

# Non-linear transformation (ReLU)
nonlinear_result = np.maximum(0, linear_result)

print("Linear:", linear_result)
print("Non-linear:", nonlinear_result)
```

This is essentially one of the fundamental building blocks of a neural network:

$$
\boxed{y = \operatorname{ReLU}(Wx+b)}
$$

Here:

- $W$ = weight matrix.
- $x$ = input vector.
- $b$ = bias vector.
- ReLU = non-linear activation function.

**My recommendation:** Learn linear algebra first (vectors, matrices, matrix multiplication, eigenvalues), then move to
non-linear equations and optimization. This progression is particularly useful if you want to understand machine learning and
neural networks.
