# Vector Calculus – explanation and Python examples

**Vector calculus** is a branch of mathematics that studies how scalar and vector fields change in space.

It combines:

- Linear algebra (vectors and matrices).
- Differential calculus (derivatives).
- Integral calculus (integrals).
- Multivariable calculus (functions with multiple variables).

Vector calculus is widely used in physics, engineering, fluid mechanics, electromagnetism, computer graphics, and machine
learning.

Let's explore its most important concepts and implement them in Python.

# 1\. Scalar fields and vector fields

First, we need to understand the difference between a scalar field and a vector field.

### Scalar field

A scalar field assigns one numerical value to every point in space.

For example, temperature:

$$
T(x,y)=x^2+y^2
$$

At every position `(x, y)`, we get one number.

Python:

python

```python
import numpy as np

def temperature(x, y):
    return x**2 + y**2

print(temperature(2, 3))
# 13
```

### Vector field

A vector field assigns a vector to every point in space.

For example:

$$
F(x,y)=
\begin{bmatrix}
x\\
y
\end{bmatrix}
$$

At every position, we get a vector.

Python:

python

```python
import numpy as np

def vector_field(x, y):
    return np.array([x, y])

print(vector_field(2, 3))
# [2 3]
```

The difference:

| Scalar field       | Vector field     |
| ------------------ | ---------------- |
| Returns a number   | Returns a vector |
| Temperature        | Wind velocity    |
| Pressure           | Fluid velocity   |
| Electric potential | Electric field   |

# 2\. Gradient (∇)

The gradient measures how quickly a scalar field changes in different directions.

It transforms a scalar field into a vector field.

Mathematically:

$$
f(x,y)=x^2+y^2
$$

The gradient is:

$$
\nabla f =
\begin{bmatrix}
\frac{\partial f}{\partial x}\\
\frac{\partial f}{\partial y}
\end{bmatrix}
$$

Calculating partial derivatives:

$$
\frac{\partial f}{\partial x}=2x
$$

$$
\frac{\partial f}{\partial y}=2y
$$

Therefore:

$$
\boxed{
\nabla f =
\begin{bmatrix}
2x\\
2y
\end{bmatrix}
}
$$

At point `(2, 3)`:

$$
\nabla f(2,3)=
\begin{bmatrix}
4\\
6
\end{bmatrix}
$$

The gradient points in the direction of the steepest increase of the function.

### Python implementation using SymPy

SymPy allows us to calculate derivatives symbolically.

python

```python
import sympy as sp

# Define variables
x, y = sp.symbols('x y')

# Define function
f = x**2 + y**2

# Calculate gradient
gradient_x = sp.diff(f, x)
gradient_y = sp.diff(f, y)

print("Gradient:")
print([gradient_x, gradient_y])

# Evaluate at point (2, 3)
result = [
    gradient_x.subs({x: 2, y: 3}),
    gradient_y.subs({x: 2, y: 3})
]

print("Gradient at (2, 3):", result)
```

Output:

text

```text
Gradient:
[2*x, 2*y]

Gradient at (2, 3): [4, 6]
```

# 3\. Divergence (∇ · F)

Divergence measures how much a vector field behaves like a source or sink at a particular point.

For a 2D vector field:

$$
F(x,y)=
\begin{bmatrix}
F_x(x,y)\\
F_y(x,y)
\end{bmatrix}
$$

Divergence is:

$$
\boxed{
\nabla \cdot F =
\frac{\partial F_x}{\partial x}
+
\frac{\partial F_y}{\partial y}
}
$$

Example:

$$
F(x,y)=
\begin{bmatrix}
x^2\\
y^2
\end{bmatrix}
$$

Therefore:

$$
\nabla \cdot F=2x+2y
$$

At point `(2, 3)`:

$$
\nabla \cdot F=4+6=10
$$

### Python implementation

python

```python
import sympy as sp

x, y = sp.symbols('x y')

# Define vector field
Fx = x**2
Fy = y**2

# Calculate divergence
divergence = sp.diff(Fx, x) + sp.diff(Fy, y)

print("Divergence:", divergence)

# Evaluate at (2, 3)
print("At (2, 3):", divergence.subs({x: 2, y: 3}))
```

Output:

text

```text
Divergence: 2*x + 2*y
At (2, 3): 10
```

Interpretation:

- Positive divergence: locally behaves like a source.
- Negative divergence: locally behaves like a sink.
- Zero divergence: locally has no net expansion or contraction.

# 4\. Curl (∇ × F)

Curl measures the local rotation of a vector field.

For a 3D vector field:

$$
F(x,y,z)=
\begin{bmatrix}
F_x\\
F_y\\
F_z
\end{bmatrix}
$$

The curl is:

$$
\nabla \times F =
\begin{bmatrix}
\frac{\partial F_z}{\partial y}-\frac{\partial F_y}{\partial z}\\
\frac{\partial F_x}{\partial z}-\frac{\partial F_z}{\partial x}\\
\frac{\partial F_y}{\partial x}-\frac{\partial F_x}{\partial y}
\end{bmatrix}
$$

Example:

$$
F(x,y,z)=
\begin{bmatrix}
-y\\
x\\
0
\end{bmatrix}
$$

Calculating curl:

$$
\nabla \times F =
\begin{bmatrix}
0\\
0\\
1-(-1)
\end{bmatrix}
$$

Therefore:

$$
\boxed{
\nabla \times F =
\begin{bmatrix}
0\\
0\\
2
\end{bmatrix}
}
$$

The vector field rotates around the Z-axis.

### Python implementation

python

```python
import sympy as sp

x, y, z = sp.symbols('x y z')

# Vector field
Fx = -y
Fy = x
Fz = 0

# Calculate curl
curl_x = sp.diff(Fz, y) - sp.diff(Fy, z)
curl_y = sp.diff(Fx, z) - sp.diff(Fz, x)
curl_z = sp.diff(Fy, x) - sp.diff(Fx, y)

curl = [curl_x, curl_y, curl_z]

print("Curl:", curl)
```

Output:

text

```text
Curl: [0, 0, 2]
```

# 5\. Line integrals

A line integral calculates the accumulated value of a field along a curve or path.

For a vector field:

$$
F(x,y)=
\begin{bmatrix}
F_x\\
F_y
\end{bmatrix}
$$

The line integral is:

$$
\boxed{
\int_C F\cdot dr
}
$$

It is particularly useful for calculating:

- Work performed by a force.
- Energy transferred along a path.
- Circulation of a fluid.
- Electromagnetic quantities.

### Python example

Consider a vector field:

$$
F(x,y)=
\begin{bmatrix}
-y\\
x
\end{bmatrix}
$$

And a circular path:

$$
x=\cos(t),\quad y=\sin(t)
$$

where $0\leq t\leq 2\pi$.

We can calculate the line integral using SymPy:

python

```python
import sympy as sp

t = sp.symbols('t')

# Circular path
x = sp.cos(t)
y = sp.sin(t)

# Vector field F = (-y, x)
Fx = -y
Fy = x

# Derivatives of the path
dx = sp.diff(x, t)
dy = sp.diff(y, t)

# Dot product F . dr
integrand = Fx * dx + Fy * dy

# Calculate line integral
result = sp.integrate(integrand, (t, 0, 2*sp.pi))

print(result)
```

Output:

text

```text
2*pi
```

The result is:

$$
\boxed{2\pi}
$$

# 6\. Laplacian (∇²)

Another important operation in vector calculus is the Laplacian.

It measures how a scalar field differs from its average local value.

For a 2D scalar function:

$$
f(x,y)
$$

The Laplacian is:

$$
\boxed{
\nabla^2 f =
\frac{\partial^2 f}{\partial x^2}
+
\frac{\partial^2 f}{\partial y^2}
}
$$

Example:

$$
f(x,y)=x^2+y^2
$$

First, calculate second derivatives:

$$
\frac{\partial^2 f}{\partial x^2}=2
$$

$$
\frac{\partial^2 f}{\partial y^2}=2
$$

Therefore:

$$
\nabla^2 f=2+2=4
$$

Python:

python

```python
import sympy as sp

x, y = sp.symbols('x y')

f = x**2 + y**2

laplacian = (
    sp.diff(f, x, 2) +
    sp.diff(f, y, 2)
)

print(laplacian)
# 4
```

The Laplacian is widely used in:

- Heat transfer.
- Fluid mechanics.
- Image processing.
- Electromagnetism.
- Wave equations.

# 7\. Summary of vector calculus operations

Here are the most important operations:

| Operation        | Mathematical notation | Purpose                                          |
| ---------------- | --------------------- | ------------------------------------------------ |
| Gradient         | $\nabla f$            | Measures direction and rate of steepest increase |
| Divergence       | $\nabla \cdot F$      | Measures expansion or contraction                |
| Curl             | $\nabla \times F$     | Measures local rotation                          |
| Laplacian        | $\nabla^2 f$          | Measures local curvature                         |
| Line integral    | $\int_C F\cdot dr$    | Accumulation along a path                        |
| Surface integral | $\iint_S F\cdot dS$   | Measures flux through a surface                  |
| Volume integral  | $\iiint_V f\,dV$      | Accumulates values over a volume                 |

## 9\. Practical example: Visualizing a vector field

Let's visualize a 2D vector field:

$$
F(x,y)=
\begin{bmatrix}
-y\\
x
\end{bmatrix}
$$

This field represents circular rotation around the origin.

python

```python
import numpy as np
import matplotlib.pyplot as plt

# Generate coordinates
x = np.linspace(-5, 5, 20)
y = np.linspace(-5, 5, 20)

X, Y = np.meshgrid(x, y)

# Vector field
U = -Y
V = X

# Visualize
plt.figure(figsize=(7, 7))

plt.quiver(X, Y, U, V)

plt.xlabel("X")
plt.ylabel("Y")
plt.title("Vector Field: F(x,y) = (-y, x)")

plt.grid()
plt.axis("equal")

plt.show()
```

This produces a vector field where arrows show the direction and magnitude of the vectors.

## 10\. How the concepts connect

One important thing to understand is that vector calculus builds on the mathematical concepts we've discussed previously.

The progression looks like this:

1. **Vectors** – represent direction and magnitude.
2. **Matrices** – represent linear transformations.
3. **Derivatives** – measure how functions change.
4. **Partial derivatives** – measure changes in individual dimensions.
5. **Gradient** – combines partial derivatives into a vector.
6. **Divergence and curl** – describe properties of vector fields.
7. **Integrals** – calculate accumulated quantities.
8. **Vector calculus** – combines all these concepts.

**My recommendation:** Start with gradient, divergence, and curl. They are three fundamental operations that will help you
understand more advanced topics such as fluid dynamics, electromagnetism, robotics, and machine learning.
