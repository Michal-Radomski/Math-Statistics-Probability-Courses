You can calculate **matrix transpose, determinant, and inverse** in Python using NumPy. Let's go through each operation,
including the mathematical formulas and Python implementations.

We'll use the following matrix throughout:

$$
A =
\begin{bmatrix}
1 & 2\\
3 & 4
\end{bmatrix}
$$

First, import NumPy:

python

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])
```

# 1\. Matrix transposition

Transposition means switching rows and columns.

For example:

$$
A =
\begin{bmatrix}
1 & 2\\
3 & 4
\end{bmatrix}
$$

After transposition:

$$
A^T =
\begin{bmatrix}
1 & 3\\
2 & 4
\end{bmatrix}
$$

Notice:

- First row becomes first column.
- Second row becomes second column.

### Python implementation

python

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

# Transpose
AT = A.T

print(AT)
```

Output:

text

```text
[[1 3]
 [2 4]]
```

You can also use:

python

```python
AT = np.transpose(A)
```

Both methods produce the same result.

### Example with a non-square matrix

Consider a 2 × 3 matrix:

$$
A =
\begin{bmatrix}
1 & 2 & 3\\
4 & 5 & 6
\end{bmatrix}
$$

Its transpose is a 3 × 2 matrix:

$$
A^T =
\begin{bmatrix}
1 & 4\\
2 & 5\\
3 & 6
\end{bmatrix}
$$

python

```python
A = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(A.T)
```

# 2\. Matrix determinant

The determinant is a single numerical value calculated from a square matrix.

For a 2 × 2 matrix:

$$
A =
\begin{bmatrix}
a & b\\
c & d
\end{bmatrix}
$$

The determinant is:

$$
\boxed{\det(A)=ad-bc}
$$

Let's calculate it for our matrix:

$$
A =
\begin{bmatrix}
1 & 2\\
3 & 4
\end{bmatrix}
$$

Therefore:

$$
\det(A) = 1\cdot4 - 2\cdot3
$$

$$
=4-6
$$

$$
\boxed{\det(A)=-2}
$$

### Python implementation

python

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

det = np.linalg.det(A)

print(det)
```

Output:

text

```text
-2.0000000000000004
```

The small difference from `-2` is due to floating-point precision.

You can also round the result:

python

```python
print(round(np.linalg.det(A)))
# -2
```

### Important: Determinant and invertibility

The determinant tells us whether a matrix has an inverse.

- If determinant ≠ 0: matrix is invertible.
- If determinant = 0: matrix is singular and has no inverse.

For example:

$$
B =
\begin{bmatrix}
1 & 2\\
2 & 4
\end{bmatrix}
$$

$$
\det(B)=1\cdot4-2\cdot2=0
$$

Therefore, matrix B cannot be inverted.

# 3\. Matrix inversion

Matrix inversion means finding another matrix that, when multiplied by the original matrix, produces the identity matrix.

Mathematically:

$$
A \cdot A^{-1}=I
$$

Where the identity matrix is:

$$
I =
\begin{bmatrix}
1 & 0\\
0 & 1
\end{bmatrix}
$$

For a 2 × 2 matrix:

$$
A =
\begin{bmatrix}
a & b\\
c & d
\end{bmatrix}
$$

The inverse is:

$$
\boxed{
A^{-1} =
\frac{1}{ad-bc}
\begin{bmatrix}
d & -b\\
-c & a
\end{bmatrix}
}
$$

Let's calculate it.

Our matrix:

$$
A =
\begin{bmatrix}
1 & 2\\
3 & 4
\end{bmatrix}
$$

We already know:

$$
\det(A)=-2
$$

Therefore:

$$
A^{-1} =
\frac{1}{-2}
\begin{bmatrix}
4 & -2\\
-3 & 1
\end{bmatrix}
$$

Result:

$$
\boxed{
A^{-1} =
\begin{bmatrix}
-2 & 1\\
1.5 & -0.5
\end{bmatrix}
}
$$

### Python implementation

python

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

# Calculate inverse
A_inv = np.linalg.inv(A)

print(A_inv)
```

Output:

text

```text
[[-2.   1. ]
 [ 1.5 -0.5]]
```

### Verify the inverse

Let's multiply the original matrix by its inverse.

python

```python
result = A @ A_inv

print(result)
```

Output:

text

```text
[[1. 0.]
 [0. 1.]]
```

We get the identity matrix\!

# 4\. Complete example: All three operations

Here is everything together:

python

```python
import numpy as np

# Create matrix
A = np.array([
    [1, 2],
    [3, 4]
])

# 1. Transposition
transpose = A.T

# 2. Determinant
determinant = np.linalg.det(A)

# 3. Inversion
inverse = np.linalg.inv(A)

# 4. Verify inverse
identity = A @ inverse

print("Original matrix:")
print(A)

print("\nTranspose:")
print(transpose)

print("\nDeterminant:")
print(determinant)

print("\nInverse:")
print(inverse)

print("\nVerification (A @ A_inv):")
print(identity)
```

# 5\. Bonus: Working with 3 × 3 matrices

These operations also work with larger matrices.

Consider:

$$
A =
\begin{bmatrix}
2 & 1 & 3\\
1 & 0 & 2\\
3 & 2 & 1
\end{bmatrix}
$$

Python:

python

```python
import numpy as np

A = np.array([
    [2, 1, 3],
    [1, 0, 2],
    [3, 2, 1]
])

print("Transpose:")
print(A.T)

print("\nDeterminant:")
print(np.linalg.det(A))

print("\nInverse:")
print(np.linalg.inv(A))
```

NumPy automatically handles the calculations regardless of whether you have a 2 × 2, 3 × 3, or larger square matrix.

## 6\. Summary of NumPy functions

| Operation             | NumPy function             | Mathematical notation    |
| --------------------- | -------------------------- | ------------------------ |
| Transposition         | `A.T`                      | $A^T$                    |
| Transposition         | `np.transpose(A)`          | $A^T$                    |
| Determinant           | `np.linalg.det(A)`         | $\det(A)$                |
| Inversion             | `np.linalg.inv(A)`         | $A^{-1}$                 |
| Identity matrix       | `np.eye(3)`                | $I$                      |
| Matrix multiplication | `A @ B`                    | $AB$                     |
| Matrix rank           | `np.linalg.matrix_rank(A)` | $\operatorname{rank}(A)$ |

**One important practical tip:** When solving a system of linear equations $Ax=b$, prefer:

python

```python
x = np.linalg.solve(A, b)
```

rather than explicitly calculating:

python

```python
x = np.linalg.inv(A) @ b
```

The `solve()` approach is generally faster and numerically more reliable.

These three operations—transposition, determinants, and inversion—are fundamental building blocks of linear algebra and are
widely used in machine learning, computer graphics, physics, and engineering.
