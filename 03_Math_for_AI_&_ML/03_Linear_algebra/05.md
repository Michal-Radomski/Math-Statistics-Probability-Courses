In Python, you can multiply two vectors in several ways, depending on what mathematical operation you want.

Let's use **NumPy**.

## 1\. Element-wise multiplication (Hadamard product)

Multiply corresponding elements of two vectors.

Mathematically:

$$
A = [1,2,3]
$$

$$
B = [4,5,6]
$$

Result:

$$
A * B = [1\cdot4,\ 2\cdot5,\ 3\cdot6]
$$

$$
= [4,10,18]
$$

Python:

python

```python
import numpy as np

A = np.array([1, 2, 3])
B = np.array([4, 5, 6])

result = A * B

print(result)
# [ 4 10 18]
```

## 2\. Dot product (scalar product)

The dot product multiplies corresponding elements and then adds the results.

Mathematically:

$$
A \cdot B = 1\cdot4 + 2\cdot5 + 3\cdot6
$$

$$
= 4+10+18=32
$$

Python:

python

```python
import numpy as np

A = np.array([1, 2, 3])
B = np.array([4, 5, 6])

result = np.dot(A, B)

print(result)
# 32
```

You can also use:

python

```python
result = A @ B
```

## 3\. Cross product (vector product)

The cross product produces a new vector perpendicular to the original two vectors.

For example:

$$
A = [1,0,0]
$$

$$
B = [0,1,0]
$$

Result:

$$
A \times B = [0,0,1]
$$

Python:

python

```python
import numpy as np

A = np.array([1, 0, 0])
B = np.array([0, 1, 0])

result = np.cross(A, B)

print(result)
# [0 0 1]
```

Note: The cross product is defined for 3D vectors (and also has a 2D scalar interpretation).

## 4\. Outer product

The outer product creates a matrix from two vectors.

Mathematically:

$$
A =
\begin{bmatrix}
1\\
2\\
3
\end{bmatrix}
$$

$$
B =
\begin{bmatrix}
4\\
5
\end{bmatrix}
$$

Result:

$$
A \otimes B =
\begin{bmatrix}
4 & 5\\
8 & 10\\
12 & 15
\end{bmatrix}
$$

Python:

python

```python
import numpy as np

A = np.array([1, 2, 3])
B = np.array([4, 5])

result = np.outer(A, B)

print(result)
```

Output:

text

```text
[[ 4  5]
 [ 8 10]
 [12 15]]
```

## Summary

| Operation     | NumPy            | Result |
| ------------- | ---------------- | ------ |
| Element-wise  | `A * B`          | Vector |
| Dot product   | `np.dot(A, B)`   | Number |
| Cross product | `np.cross(A, B)` | Vector |
| Outer product | `np.outer(A, B)` | Matrix |

**Important:** In linear algebra, when someone says "multiply two vectors", they usually mean the dot product or cross
