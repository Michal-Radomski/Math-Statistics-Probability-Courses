In Python, you can work with vectors using several libraries. The most popular option is **NumPy**.

## 1\. Using NumPy (recommended)

A vector is essentially a one-dimensional array of numbers.

python

```python
import numpy as np

# Create vectors
v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])

# Vector addition
print(v1 + v2)
# [5 7 9]

# Vector subtraction
print(v1 - v2)
# [-3 -3 -3]

# Scalar multiplication
print(v1 * 2)
# [2 4 6]

# Dot product
print(np.dot(v1, v2))
# 32

# Vector magnitude (length)
print(np.linalg.norm(v1))
# 3.741657...

# Normalize vector
normalized = v1 / np.linalg.norm(v1)
print(normalized)
```

## 2\. Using NumPy for 2D and 3D vectors

You can also represent vectors in 2D or 3D space.

python

```python
import numpy as np

# 2D vectors
position = np.array([10, 20])
direction = np.array([1, 0])

new_position = position + direction * 5

print(new_position)
# [15 20]
```

3D example:

python

```python
import numpy as np

a = np.array([1, 0, 0])
b = np.array([0, 1, 0])

# Cross product
cross = np.cross(a, b)

print(cross)
# [0 0 1]
```

## 3\. Using SciPy

If you're doing scientific computing, you can also use SciPy, which builds on NumPy.

python

```python
import numpy as np
from scipy.spatial.distance import euclidean

v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])

distance = euclidean(v1, v2)

print(distance)
# 5.196152...
```

## 4\. Using a Python list (without libraries)

You can also implement basic vector operations yourself.

python

```python
v1 = [1, 2, 3]
v2 = [4, 5, 6]

# Addition
addition = [a + b for a, b in zip(v1, v2)]

# Subtraction
subtraction = [a - b for a, b in zip(v1, v2)]

# Dot product
dot = sum(a * b for a, b in zip(v1, v2))

print(addition)     # [5, 7, 9]
print(subtraction)  # [-3, -3, -3]
print(dot)          # 32
```

## Which library should you use?

| Library    | Best for                                |
| ---------- | --------------------------------------- |
| NumPy      | General vector and matrix operations    |
| SciPy      | Scientific computing and linear algebra |
| PyTorch    | Machine learning and GPU computations   |
| TensorFlow | Deep learning and tensor operations     |
| SymPy      | Symbolic mathematics and algebra        |

**My recommendation:** Start with NumPy. It provides almost everything you need for working with mathematical vectors,
matrices, dot products, cross products, and linear algebra.
