# What is an Abstract Vector?

An **abstract vector** is a mathematical object that follows the rules of vector operations, such as addition and scalar
multiplication, but does not necessarily represent a physical arrow or a list of numbers.

In other words, a vector does not have to be a coordinate such as `[1, 2, 3]`.

It can represent:

- A polynomial.
- A mathematical function.
- A sequence of numbers.
- A matrix.
- A signal.
- A geometric object.

The important thing is that it satisfies the mathematical rules of a **vector space**.

## 1\. Traditional vector vs. abstract vector

Let's compare two examples.

### Traditional vector

A traditional vector represents a point or direction in space.

For example:

$$
v =
\begin{bmatrix}
2\\
3
\end{bmatrix}
$$

Python:

python

```python
import numpy as np

v = np.array([2, 3])

print(v)
```

We can perform vector operations:

python

```python
v1 = np.array([1, 2])
v2 = np.array([3, 4])

# Addition
print(v1 + v2)

# Scalar multiplication
print(2 * v1)
```

### Abstract vector

Now imagine that instead of coordinates, our vector is a polynomial:

$$
p(x)=2x^2+3x+1
$$

This polynomial can also be considered a vector.

For example, we can add two polynomials:

$$
p(x)=2x^2+3x+1
$$

$$
q(x)=x^2+4x+2
$$

Their sum is:

$$
p(x)+q(x)=3x^2+7x+3
$$

We can also multiply a polynomial by a scalar:

$$
2p(x)=4x^2+6x+2
$$

These operations follow the rules of vector addition and scalar multiplication.

Therefore, polynomials can form a vector space.

## 2\. Example: Polynomials as vectors in Python

We can use SymPy to work with polynomials.

python

```python
import sympy as sp

x = sp.symbols('x')

# Define two polynomials
p = 2*x**2 + 3*x + 1
q = x**2 + 4*x + 2

# Vector addition
result = p + q

print(result)
# 3*x**2 + 7*x + 3

# Scalar multiplication
result = 2 * p

print(result)
# 4*x**2 + 6*x + 2
```

Notice that we are performing vector-like operations without using traditional numerical vectors.

## 3\. Example: Matrices as abstract vectors

Matrices can also be vectors in a mathematical vector space.

Consider:

$$
A =
\begin{bmatrix}
1 & 2\\
3 & 4
\end{bmatrix}
$$

And:

$$
B =
\begin{bmatrix}
5 & 6\\
7 & 8
\end{bmatrix}
$$

We can add them:

$$
A+B=
\begin{bmatrix}
6 & 8\\
10 & 12
\end{bmatrix}
$$

We can multiply a matrix by a scalar:

$$
2A=
\begin{bmatrix}
2 & 4\\
6 & 8
\end{bmatrix}
$$

Python:

python

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

B = np.array([
    [5, 6],
    [7, 8]
])

# Abstract vector addition
print(A + B)

# Scalar multiplication
print(2 * A)
```

Here, matrices are treated as individual elements of a vector space.

**Important:** Matrix multiplication is not the vector addition operation in this vector space. Matrix addition and scalar
multiplication are.

## 4\. What makes something a vector?

In abstract linear algebra, a vector space must satisfy eight properties.

For vectors $u,v,w$ and scalars $a,b$:

| Property                    | Mathematical rule |
| --------------------------- | ----------------- |
| Commutativity               | $u+v=v+u$         |
| Associativity               | $(u+v)+w=u+(v+w)$ |
| Zero vector                 | $v+0=v$           |
| Additive inverse            | $v+(-v)=0$        |
| Scalar associativity        | $a(bv)=(ab)v$     |
| Scalar identity             | $1v=v$            |
| Distributivity over vectors | $a(u+v)=au+av$    |
| Distributivity over scalars | $(a+b)v=av+bv$    |

If a set of objects and its operations satisfy these rules, it forms a vector space.

## 5\. Examples of abstract vector spaces

| Vector space     | Example of a vector |
| ---------------- | ------------------- |
| $\mathbb{R}^2$   | `[2, 3]`            |
| $\mathbb{R}^3$   | `[1, 2, 3]`         |
| Polynomial space | $2x^2+3x+1$         |
| Matrix space     | A 2 × 2 matrix      |
| Function space   | $f(x)=\sin(x)$      |
| Sequence space   | `[1, 2, 3, 4, ...]` |

## 6\. Why are abstract vectors important?

Abstract vectors allow mathematicians and engineers to use the same mathematical framework for completely different problems.

For example:

- **Machine learning:** Data points, model parameters, and feature vectors.
- **Computer graphics:** Coordinates and transformations.
- **Signal processing:** Signals can be represented as vectors in function spaces.
- **Quantum mechanics:** Quantum states are represented by vectors in abstract vector spaces.
- **Differential equations:** Solutions can belong to vector spaces of functions.

---

### The most important distinction

Think about it this way:

A traditional vector is usually represented as a list of numbers:

$$
v=[1,2,3]
$$

An abstract vector is any mathematical object that behaves like a vector under addition and scalar multiplication.

**A vector is not defined by what it represents, but by the mathematical operations and properties it satisfies.**

This is one of the fundamental ideas of abstract linear algebra.
