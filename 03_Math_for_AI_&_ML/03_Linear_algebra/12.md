# Eigenvalues and Eigenvectors

**Eigenvalues and eigenvectors are fundamental concepts in linear algebra.** They describe special directions in which a
matrix transformation only stretches, shrinks, or reverses a vector without changing its direction.

They are widely used in:

- Machine learning and artificial intelligence.
- Principal Component Analysis (PCA).
- Computer graphics.
- Physics and quantum mechanics.
- Dimensionality reduction.
- Stability analysis.
- Differential equations.

Let's understand the mathematics and then implement everything in Python using NumPy.

## 1\. What is an eigenvector?

Imagine you have a matrix that transforms vectors.

Normally, when you multiply a matrix by a vector, the vector can change both its length and direction.

However, some special vectors retain their direction after the transformation.

These are called **eigenvectors**.

Mathematically:

$$
\boxed{Av=\lambda v}
$$

Where:

- $A$ = square matrix.
- $v$ = eigenvector.
- $\lambda$ = eigenvalue.
- $Av$ = transformed vector.

The eigenvalue tells us how much the eigenvector is scaled.

For example:

- Eigenvalue = 2: vector doubles in length.
- Eigenvalue = 0.5: vector becomes half its length.
- Eigenvalue = -1: vector reverses direction but keeps its length.
- Eigenvalue = 0: vector collapses to zero.

## 2\. Mathematical example

Consider the following matrix:

$$
A =
\begin{bmatrix}
2 & 0\\
0 & 3
\end{bmatrix}
$$

Let's choose a vector:

$$
v =
\begin{bmatrix}
1\\
0
\end{bmatrix}
$$

Multiply the matrix by the vector:

$$
Av =
\begin{bmatrix}
2 & 0\\
0 & 3
\end{bmatrix}
\begin{bmatrix}
1\\
0
\end{bmatrix}
$$

Result:

$$
Av =
\begin{bmatrix}
2\\
0
\end{bmatrix}
$$

Notice that:

$$
Av=2v
$$

Therefore:

- Eigenvector: $v=[1,0]^T$
- Eigenvalue: $\lambda=2$

Let's try another vector:

$$
v =
\begin{bmatrix}
0\\
1
\end{bmatrix}
$$

Multiplication:

$$
Av =
\begin{bmatrix}
2 & 0\\
0 & 3
\end{bmatrix}
\begin{bmatrix}
0\\
1
\end{bmatrix}
$$

Result:

$$
Av =
\begin{bmatrix}
0\\
3
\end{bmatrix}
$$

Therefore:

$$
Av=3v
$$

So:

- Eigenvector: $v=[0,1]^T$
- Eigenvalue: $\lambda=3$

We have found two eigenvectors and their corresponding eigenvalues.

## 3\. How to calculate eigenvalues mathematically

We start with:

$$
Av=\lambda v
$$

Rearrange:

$$
Av-\lambda v=0
$$

Factor out the vector:

$$
(A-\lambda I)v=0
$$

Where $I$ is the identity matrix.

For a non-zero eigenvector to exist, the following must be true:

$$
\boxed{\det(A-\lambda I)=0}
$$

This is called the **characteristic equation**.

Let's use our matrix:

$$
A =
\begin{bmatrix}
2 & 0\\
0 & 3
\end{bmatrix}
$$

Calculate:

$$
\det
\begin{bmatrix}
2-\lambda & 0\\
0 & 3-\lambda
\end{bmatrix}=0
$$

For a 2 × 2 matrix, the determinant is:

$$
(2-\lambda)(3-\lambda)=0
$$

Therefore:

$$
\lambda_1=2
$$

$$
\lambda_2=3
$$

These are our eigenvalues.

## 4\. Calculating eigenvalues and eigenvectors in Python

NumPy provides a function called `np.linalg.eig()`.

Let's calculate eigenvalues and eigenvectors automatically.

python

```python
import numpy as np

# Define matrix
A = np.array([
    [2, 0],
    [0, 3]
])

# Calculate eigenvalues and eigenvectors
eigenvalues, eigenvectors = np.linalg.eig(A)

print("Eigenvalues:")
print(eigenvalues)

print("\nEigenvectors:")
print(eigenvectors)
```

Output:

text

```text
Eigenvalues:
[2. 3.]

Eigenvectors:
[[1. 0.]
 [0. 1.]]
```

Notice something important:

- First column is the eigenvector corresponding to eigenvalue 2.
- Second column is the eigenvector corresponding to eigenvalue 3.

NumPy stores eigenvectors as **columns**, not rows.

## 6\. Verify eigenvalues and eigenvectors

We can verify the fundamental equation:

$$
Av=\lambda v
$$

Python:

python

```python
import numpy as np

A = np.array([
    [4, 2],
    [1, 3]
])

eigenvalues, eigenvectors = np.linalg.eig(A)

for i in range(len(eigenvalues)):

    eigenvalue = eigenvalues[i]
    eigenvector = eigenvectors[:, i]

    left = A @ eigenvector
    right = eigenvalue * eigenvector

    print(f"\nEigenvalue: {eigenvalue}")

    print("A @ v:")
    print(left)

    print("lambda * v:")
    print(right)

    print("Verification:")
    print(np.allclose(left, right))
```

Output:

text

```text
Verification:
True

Verification:
True
```

This confirms that the eigenvalues and eigenvectors satisfy the mathematical equation.

## 7\. Calculating eigenvalues using SymPy

NumPy calculates numerical approximations.

However, sometimes you want exact mathematical results.

For this, you can use SymPy.

python

```python
import sympy as sp

A = sp.Matrix([
    [4, 2],
    [1, 3]
])

# Calculate eigenvalues
eigenvalues = A.eigenvals()

print("Eigenvalues:")
print(eigenvalues)

# Calculate eigenvectors
eigenvectors = A.eigenvects()

print("\nEigenvectors:")
for item in eigenvectors:
    eigenvalue = item[0]
    vectors = item[2]

    print("Eigenvalue:", eigenvalue)
    print("Eigenvector:", vectors)
```

SymPy gives exact results:

$$
\lambda_1=5,\qquad \lambda_2=2
$$

Corresponding eigenvector directions:

$$
v_1=
\begin{bmatrix}
2\\
1
\end{bmatrix}
$$

$$
v_2=
\begin{bmatrix}
-1\\
1
\end{bmatrix}
$$

Notice that eigenvectors can be multiplied by any non-zero scalar and remain eigenvectors.

For example:

$$
\begin{bmatrix}
2\\
1
\end{bmatrix}
$$

and

$$
\begin{bmatrix}
0.8944\\
0.4472
\end{bmatrix}
$$

represent the same eigenvector direction.

# 8\. Eigenvalues and eigenvectors in machine learning

One particularly important application is **Principal Component Analysis (PCA)**.

PCA is a technique used to reduce the number of dimensions in a dataset while preserving as much information (variance) as
possible.

Imagine you have a dataset with 100 features.

You want to reduce it to 2 features.

PCA uses eigenvalues and eigenvectors of the covariance matrix.

The process:

1. Calculate the covariance matrix.
2. Calculate its eigenvalues and eigenvectors.
3. Sort eigenvalues from largest to smallest.
4. Select eigenvectors corresponding to the largest eigenvalues.
5. Project the original data onto the selected eigenvectors.

### Python example using PCA

We can use scikit-learn:

bash

```bash
pip install numpy scikit-learn matplotlib
```

python

```python
import numpy as np
import matplotlib.pyplot as plt

from sklearn.decomposition import PCA
from sklearn.datasets import make_blobs

# Generate sample dataset with 3 features
X, y = make_blobs(
    n_samples=200,
    centers=3,
    n_features=3,
    random_state=42
)

# Apply PCA
pca = PCA(n_components=2)

X_reduced = pca.fit_transform(X)

print("Original shape:", X.shape)
print("Reduced shape:", X_reduced.shape)

print("Explained variance:")
print(pca.explained_variance_ratio_)

# Visualize reduced data
plt.scatter(
    X_reduced[:, 0],
    X_reduced[:, 1],
    c=y
)

plt.xlabel("Principal Component 1")
plt.ylabel("Principal Component 2")
plt.title("PCA - Dimensionality Reduction")

plt.show()
```

Here:

- Original dataset has 3 dimensions.
- PCA reduces it to 2 dimensions.
- Eigenvectors determine the new coordinate directions.
- Eigenvalues indicate how much variance each direction captures.
