# Gradient Descent and Gradient Ascent

**Gradient descent and gradient ascent are optimization algorithms used to find the minimum or maximum value of a
mathematical function.**

They are based on the concept of the gradient, which we discussed in vector calculus.

The main difference:

- **Gradient descent:** Moves towards the minimum of a function.
- **Gradient ascent:** Moves towards the maximum of a function.

Both algorithms use derivatives to determine which direction to move.

## 1\. Understanding the concept

Imagine you are standing on a mountain.

- If you want to reach the bottom of the mountain, you walk downhill. This is gradient descent.
- If you want to reach the top of the mountain, you walk uphill. This is gradient ascent.

Mathematically, the gradient tells you the direction of the steepest increase.

Therefore:

- To minimize a function, move in the opposite direction of the gradient.
- To maximize a function, move in the same direction as the gradient.

## 2\. Gradient descent

Let's consider a simple mathematical function:

$$
f(x)=x^2
$$

Our goal is to find the minimum value.

The derivative is:

$$
f'(x)=2x
$$

The gradient descent formula is:

$$
\boxed{x_{new}=x_{old}-\alpha f'(x)}
$$

Where:

- $x$ = current position.
- $\alpha$ = learning rate (step size).
- $f'(x)$ = derivative (gradient).

### Example

Let's start at:

$$
x=5
$$

And choose a learning rate:

$$
\alpha=0.1
$$

First iteration:

$$
x_{new}=5-0.1(2\cdot5)
$$

$$
x_{new}=4
$$

Second iteration:

$$
x_{new}=4-0.1(2\cdot4)
$$

$$
x_{new}=3.2
$$

Third iteration:

$$
x_{new}=3.2-0.1(2\cdot3.2)
$$

$$
x_{new}=2.56
$$

We are moving closer to the minimum, which is at:

$$
\boxed{x=0}
$$

### Python implementation

We can implement gradient descent without using any external optimization library.

python

```python
import numpy as np

# Function: f(x) = x²
def f(x):
    return x**2

# Derivative: f'(x) = 2x
def gradient(x):
    return 2*x

# Initial position
x = 5.0

# Learning rate
learning_rate = 0.1

# Gradient descent iterations
for i in range(20):
    x = x - learning_rate * gradient(x)

    print(f"Iteration {i+1}: x={x:.6f}, f(x)={f(x):.6f}")

print("Minimum:", x)
```

As iterations increase, `x` approaches zero.

## 3\. Gradient ascent

Gradient ascent works in the opposite direction.

Let's consider:

$$
f(x)=-(x-3)^2+9
$$

This function has its maximum at:

$$
x=3
$$

Its derivative is:

$$
f'(x)=-2(x-3)
$$

The gradient ascent formula is:

$$
\boxed{x_{new}=x_{old}+\alpha f'(x)}
$$

Notice the `+` instead of `-`.

### Python implementation

python

```python
# Function
def f(x):
    return -(x - 3)**2 + 9

# Derivative
def gradient(x):
    return -2 * (x - 3)

# Initial position
x = 8.0

# Learning rate
learning_rate = 0.1

# Gradient ascent
for i in range(20):
    x = x + learning_rate * gradient(x)

    print(f"Iteration {i+1}: x={x:.6f}, f(x)={f(x):.6f}")

print("Maximum:", x)
```

The result approaches:

text

```text
Maximum: 3.057646
```

The exact maximum is at `x = 3`.

## 4\. Visual comparison

Consider these two functions:

**Gradient descent:**

$$

Find the minimum.

**Gradient ascent:**

$$

Find the maximum.

## 5\. Gradient descent with multiple variables

This is where things become particularly interesting.

So far, we've optimized functions with one variable.

But what happens when we have multiple variables?

Consider:

$$
f(x,y)=x^2+y^2
$$

We want to find its minimum.

The gradient is:

$$
\nabla f(x,y)=
\begin{bmatrix}
2x\\
2y
\end{bmatrix}
$$

The gradient descent formula becomes:

$$
\boxed{
\begin{bmatrix}
x_{new}\\
y_{new}
\end{bmatrix}
=
\begin{bmatrix}
x_{old}\\
y_{old}
\end{bmatrix}
-
\alpha
\begin{bmatrix}
2x\\
2y
\end{bmatrix}
}
$$

We are now optimizing a function in two-dimensional space.

### Python implementation using NumPy

python

```python
import numpy as np

# Function
def f(x):
    return x[0]**2 + x[1]**2

# Gradient
def gradient(x):
    return np.array([
        2*x[0],
        2*x[1]
    ])

# Initial position
x = np.array([5.0, 8.0])

# Learning rate
learning_rate = 0.1

# Gradient descent
for i in range(100):

    grad = gradient(x)

    x = x - learning_rate * grad

print("Minimum position:", x)
print("Minimum value:", f(x))
```

Result:

text

```text
Minimum position: [approximately 0, approximately 0]
Minimum value: approximately 0
```

The minimum is at:

$$
(x,y)=(0,0)
$$

## 6\. Gradient descent vs. gradient ascent

| Feature          | Gradient descent   | Gradient ascent     |
| ---------------- | ------------------ | ------------------- |
| Purpose          | Find minimum       | Find maximum        |
| Direction        | Opposite gradient  | Same as gradient    |
| Formula          | $x-\alpha\nabla f$ | $x+\alpha\nabla f$  |
| Application      | Minimize error     | Maximize reward     |
| Machine learning | Model training     | Reward optimization |

## 7\. Where are they used?

Both algorithms are fundamental to optimization.

| Application                 | Algorithm                     |
| --------------------------- | ----------------------------- |
| Training neural networks    | Gradient descent              |
| Linear regression           | Gradient descent              |
| Logistic regression         | Gradient descent              |
| Minimizing prediction error | Gradient descent              |
| Maximizing expected reward  | Gradient ascent               |
| Reinforcement learning      | Both, depending on the method |
| Scientific optimization     | Both                          |

### 8\. An important concept: Learning rate

The learning rate determines how big a step the algorithm takes.

For example:

python

```python
learning_rate = 0.001  # Small steps
learning_rate = 0.1    # Medium steps
learning_rate = 1.0    # Large steps
```

- Too small: optimization can be very slow.
- Too large: the algorithm can overshoot the minimum or maximum and potentially diverge.
- Appropriate: converges efficiently towards the solution.

## 9\. Connection to neural networks

This is probably the most important practical application.

When training a neural network, we want to minimize its prediction error (loss function).

For example:

$$
Loss = (y_{predicted}-y_{actual})^2
$$

The training process looks roughly like this:

1. Initialize neural network weights.
2. Make predictions.
3. Calculate the loss.
4. Calculate gradients using backpropagation.
5. Update weights using gradient descent.
6. Repeat until the model improves sufficiently.

The weight update formula is:

$$
\boxed{W_{new}=W_{old}-\alpha\nabla Loss(W)}
$$

Here, $W$ represents the neural network's weights.

**The key takeaway:** Gradient descent and gradient ascent are optimization techniques that use derivatives to find the
minimum or maximum of a function. Gradient descent is particularly important because it is one of the fundamental algorithms
behind modern machine learning and deep learning.
