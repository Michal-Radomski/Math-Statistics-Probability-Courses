Let's use NumPy to demonstrate the difference between **element-wise matrix multiplication** and **matrix dot product (matrix
multiplication)**.

## 1\. Element-wise multiplication (Hadamard product)

Element-wise multiplication means multiplying corresponding elements at the same positions in both matrices.

Let's define two matrices:

$$
A =
\begin{bmatrix}
1 & 2\\
3 & 4
\end{bmatrix}
$$

$$
B =
\begin{bmatrix}
5 & 6\\
7 & 8
\end{bmatrix}
$$

Multiplication:

$$
A * B =
\begin{bmatrix}
1\cdot5 & 2\cdot6\\
3\cdot7 & 4\cdot8
\end{bmatrix}
$$

Result:

$$
\boxed{
\begin{bmatrix}
5 & 12\\
21 & 32
\end{bmatrix}
}
$$

**Python:**

python

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

B = np.array([
    [5, 6],
    [7, 8]
])

# Element-wise multiplication
C = A * B

print(C)
```

Output:

text

```text
[[ 5 12]
 [21 32]]
```

## 2\. Dot product (matrix multiplication)

Matrix multiplication works differently.

Instead of multiplying corresponding elements, we multiply rows of the first matrix by columns of the second matrix and sum
the results.

Using the same matrices:

$$
A =
\begin{bmatrix}
1 & 2\\
3 & 4
\end{bmatrix}
$$

$$
B =
\begin{bmatrix}
5 & 6\\
7 & 8
\end{bmatrix}
$$

First, calculate each element of the resulting matrix.

**Top-left:**

$$
(1\cdot5)+(2\cdot7)=19
$$

**Top-right:**

$$
(1\cdot6)+(2\cdot8)=22
$$

**Bottom-left:**

$$
(3\cdot5)+(4\cdot7)=43
$$

**Bottom-right:**

$$
(3\cdot6)+(4\cdot8)=50
$$

Final result:

$$
\boxed{
\begin{bmatrix}
19 & 22\\
43 & 50
\end{bmatrix}
}
$$

**Python:**

python

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

B = np.array([
    [5, 6],
    [7, 8]
])

# Matrix multiplication
C = A @ B

print(C)
```

Output:

text

```text
[[19 22]
 [43 50]]
```

You can also use:

python

```python
C = np.dot(A, B)
```

## 3\. Visual comparison

| Operation             | NumPy   | Result                 |
| --------------------- | ------- | ---------------------- |
| Element-wise          | `A * B` | `[[5, 12], [21, 32]]`  |
| Matrix multiplication | `A @ B` | `[[19, 22], [43, 50]]` |

## 4\. Important: Matrix dimensions

There is one important difference between these operations.

**Element-wise multiplication:**

- Both matrices must have compatible shapes (usually identical dimensions).
- Each element is multiplied by the corresponding element.

**Matrix multiplication:**

- The number of columns in the first matrix must equal the number of rows in the second matrix.
- The resulting matrix has dimensions `(rows of A, columns of B)`.

For example:

python

```python
A = np.array([
    [1, 2, 3],
    [4, 5, 6]
])  # 2x3

B = np.array([
    [7, 8],
    [9, 10],
    [11, 12]
])  # 3x2

C = A @ B

print(C)
```

Output:

text

```text
[[ 58  64]
 [139 154]]
```

Here:

- A has dimensions 2 × 3.
- B has dimensions 3 × 2.
- C has dimensions 2 × 2.

**Remember:**

- `A * B` → Multiply elements individually.
- `A @ B` → Multiply rows by columns.

This distinction is fundamental to understanding linear algebra and neural networks.
