In Python, tensors are multidimensional arrays. You can think of them as an extension of vectors and matrices.

The most popular libraries for working with tensors are:

- **NumPy** – general numerical computing.
- **PyTorch** – machine learning and deep learning.
- **TensorFlow** – machine learning and neural networks.

Let's look at some examples.

# 1\. Understanding tensor dimensions

A tensor has a number of dimensions (also called its rank).

| Structure | Example             | Dimensions     | Rank |
| --------- | ------------------- | -------------- | ---- |
| Scalar    | `5`                 | `()`           | 0    |
| Vector    | `[1, 2, 3]`         | `(3,)`         | 1    |
| Matrix    | `[[1, 2], [3, 4]]`  | `(2, 2)`       | 2    |
| 3D tensor | Multiple matrices   | `(2, 2, 3)`    | 3    |
| 4D tensor | Multiple 3D tensors | `(2, 3, 4, 5)` | 4    |

# 2\. Creating tensors with NumPy

NumPy arrays can represent tensors of any number of dimensions.

python

```python
import numpy as np

# Scalar (0D tensor)
scalar = np.array(5)

# Vector (1D tensor)
vector = np.array([1, 2, 3])

# Matrix (2D tensor)
matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

# 3D tensor
tensor_3d = np.array([
    [
        [1, 2],
        [3, 4]
    ],
    [
        [5, 6],
        [7, 8]
    ]
])

print("Scalar:", scalar.shape)
print("Vector:", vector.shape)
print("Matrix:", matrix.shape)
print("3D tensor:", tensor_3d.shape)
```

Output:

text

```text
Scalar: ()
Vector: (3,)
Matrix: (2, 3)
3D tensor: (2, 2, 2)
```

# 3\. Tensor operations

You can perform mathematical operations on tensors just like matrices.

python

```python
import numpy as np

A = np.array([
    [
        [1, 2],
        [3, 4]
    ],
    [
        [5, 6],
        [7, 8]
    ]
])

B = np.array([
    [
        [10, 20],
        [30, 40]
    ],
    [
        [50, 60],
        [70, 80]
    ]
])

# Element-wise addition
print(A + B)

# Element-wise multiplication
print(A * B)

# Scalar multiplication
print(A * 2)

# Sum of all elements
print(np.sum(A))

# Average
print(np.mean(A))
```

Notice that most NumPy operations work with tensors without requiring special functions.

# 4\. Tensor multiplication

There are different ways to multiply tensors.

Let's start with element-wise multiplication.

python

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

B = np.array([
    [5, 6],
    [7, 8]
])

# Element-wise multiplication
print(A * B)

# Matrix multiplication
print(A @ B)
```

Results:

**Element-wise:**

text

```text
[[ 5 12]
 [21 32]]
```

**Matrix multiplication:**

text

```text
[[19 22]
 [43 50]]
```

You can also perform higher-dimensional tensor operations.

For example, `np.tensordot()`:

python

```python
import numpy as np

A = np.ones((2, 3, 4))
B = np.ones((4, 3, 2))

result = np.tensordot(A, B, axes=([2, 1], [0, 1]))

print(result.shape)
# (2, 2)
```

This contracts the last two dimensions of `A` against the first two dimensions of `B`.

# 5\. Using PyTorch tensors

PyTorch is particularly interesting because it provides tensor operations, GPU support, and automatic differentiation.

Install it:

bash

```bash
pip install torch
```

Create tensors:

python

```python
import torch

# Scalar
a = torch.tensor(5)

# Vector
b = torch.tensor([1, 2, 3])

# Matrix
c = torch.tensor([
    [1, 2],
    [3, 4]
])

# 3D tensor
d = torch.tensor([
    [[1, 2], [3, 4]],
    [[5, 6], [7, 8]]
])

print(a.shape)  # torch.Size([])
print(b.shape)  # torch.Size([3])
print(c.shape)  # torch.Size([2, 2])
print(d.shape)  # torch.Size([2, 2, 2])
```

# 6\. Tensor operations with PyTorch

Let's perform some mathematical operations.

python

```python
import torch

A = torch.tensor([
    [1.0, 2.0],
    [3.0, 4.0]
])

B = torch.tensor([
    [5.0, 6.0],
    [7.0, 8.0]
])

# Element-wise multiplication
print(A * B)

# Matrix multiplication
print(A @ B)

# Transpose
print(A.T)

# Matrix determinant
print(torch.linalg.det(A))

# Matrix inverse
print(torch.linalg.inv(A))
```

PyTorch also supports automatic differentiation:

python

```python
import torch

x = torch.tensor(3.0, requires_grad=True)

# Mathematical function
y = x**2 + 2*x + 1

# Calculate derivative
y.backward()

print(x.grad)

# 8.0
```

Why 8?

Because:

$$
y=x^2+2x+1
$$

Its derivative is:

$$
\frac{dy}{dx}=2x+2
$$

At $x=3$:

$$
2(3)+2=8
$$

This functionality is fundamental to training neural networks.

# 7\. Real-world example: Images as tensors

One of the most common applications of tensors is image processing.

An RGB image can be represented as a 3D tensor:

$$
\text{Image} = Height \times Width \times Channels
$$

For example, a 256 × 256 RGB image:

python

```python
import torch

image = torch.rand(256, 256, 3)

print(image.shape)

# torch.Size([256, 256, 3])
```

The three channels represent:

- Red
- Green
- Blue

For deep learning, PyTorch commonly uses a different arrangement:

python

```python
image = torch.rand(3, 256, 256)
```

For a batch of 32 images:

python

```python
images = torch.rand(32, 3, 256, 256)

print(images.shape)
```

Output:

text

```text
torch.Size([32, 3, 256, 256])
```

This is a 4D tensor:

- 32 = number of images.
- 3 = color channels.
- 256 = image height.
- 256 = image width.

# 8\. NumPy vs. PyTorch vs. TensorFlow

| Feature                   | NumPy               | PyTorch | TensorFlow |
| ------------------------- | ------------------- | ------- | ---------- |
| Multidimensional arrays   | Yes                 | Yes     | Yes        |
| Matrix operations         | Yes                 | Yes     | Yes        |
| GPU support               | Limited             | Yes     | Yes        |
| Automatic differentiation | No                  | Yes     | Yes        |
| Deep learning             | Not designed for it | Yes     | Yes        |
| Scientific computing      | Excellent           | Good    | Good       |

## What should you learn next?

I recommend following this progression:

1. **Vectors** – 1D arrays and vector operations.
2. **Matrices** – 2D arrays and matrix multiplication.
3. **Tensors** – 3D and 4D arrays.
4. **Tensor operations** – broadcasting, dot products, tensor contractions.
5. **Derivatives and gradients** – understanding how functions change.
6. **Neural networks** – combining tensors, matrix multiplication, and derivatives.

The important concept is that **vectors and matrices are special cases of tensors**. Tensors provide a general mathematical
structure for representing and manipulating multidimensional data.
