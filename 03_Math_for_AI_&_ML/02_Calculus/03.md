In Python, integration is typically handled in two different ways depending on what you need: **symbolic integration**
(finding exact algebraic formulas or antiderivatives) and **numerical integration** (approximating the numerical value of a
definite integral).

The two primary libraries used for this are **SymPy** (for symbolic math) and **SciPy** (for numerical calculations).

---

### 1. Symbolic Integration with SymPy

If you want to find the exact antiderivative or evaluate a definite integral algebraically (just like doing it by hand), you
use `SymPy`.

First, install it if you haven't already (`pip install sympy`), then run:

```python
import sympy as sp

# Define the variable
x = sp.Symbol('x')

# Define the function, e.g., f(x) = x**2 + 3*x
f = x**2 + 3*x

# 1. Indefinite Integration (Antiderivative)
antiderivative = sp.integrate(f, x)
print("Antiderivative:", antiderivative)  # Output: x**3/3 + 3*x**2/2

# 2. Definite Integration (from x = 1 to x = 3)
definite_integral = sp.integrate(f, (x, 1, 3))
print("Definite Integral:", definite_integral)  # Output: 31/3 (or ~10.33)

```

---

### 2. Numerical Integration with SciPy

If your function is too complex to integrate analytically, or if you are working with experimental data, you use
`scipy.integrate.quad` to approximate definite integrals numerically.

First, install SciPy (`pip install scipy`), then run:

```python
import scipy.integrate as spi
import numpy as np

# Define the function you want to integrate, e.g., f(x) = sin(x)
def f(x):
    return np.sin(x)

# Integrate from 0 to pi (3.14159...)
# quad returns the value and an estimate of the absolute error
result, error = spi.quad(f, 0, np.pi)

print("Numerical Result:", result)  # Output: 2.0
print("Estimated Error:", error)

```
