You can calculate the area under a **Gaussian (normal) distribution** in both Python and JavaScript/TypeScript.

This is particularly useful in statistics, probability theory, machine learning, and data analysis.

Let's use the same mathematical example in both languages.

# 1\. Understanding the Gaussian distribution

The Gaussian probability density function (PDF) is:

$$
f(x)=\frac{1}{\sigma\sqrt{2\pi}}
e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

Where:

- $\mu$ = mean (center of the distribution).
- $\sigma$ = standard deviation (spread).
- $e$ = Euler's number.
- $\pi$ = mathematical constant pi.

Let's assume:

$$
\mu=0,\qquad \sigma=1
$$

This gives us the standard normal distribution.

## 2\. Calculating the area under the curve

Suppose we want to calculate the area between:

$$
a=-1,\qquad b=1
$$

Mathematically:

$$
A=\int_{-1}^{1}
\frac{1}{\sqrt{2\pi}}e^{-\frac{x^2}{2}}\,dx
$$

The result is approximately:

$$
\boxed{A=0.682689}
$$

This means approximately **68.27% of the probability** lies within one standard deviation of the mean.

# 3\. Python implementation

Python makes this particularly easy using SciPy.

### Example A: Calculate the area using numerical integration

python

```python
import numpy as np
from scipy.integrate import quad

# Gaussian parameters
mu = 0
sigma = 1

# Gaussian probability density function
def gaussian(x):
    return (1 / (sigma * np.sqrt(2 * np.pi))) * \
           np.exp(-((x - mu)**2) / (2 * sigma**2))

# Integration limits
a = -1
b = 1

# Calculate area
area, error = quad(gaussian, a, b)

print("Area under Gaussian:", area)
print("Estimated numerical error:", error)

print("Probability (%):", area * 100)
```

Expected output:

text

```text
Area under Gaussian: 0.6826894921370859
Probability (%): 68.26894921370859
```

### Example B: Calculate the area using the cumulative distribution function

There is an even simpler approach using `scipy.stats.norm`.

python

```python
from scipy.stats import norm

# Gaussian parameters
mu = 0
sigma = 1

# Integration limits
a = -1
b = 1

# Calculate probability
area = norm.cdf(b, mu, sigma) - norm.cdf(a, mu, sigma)

print("Area:", area)
print("Probability:", area * 100, "%")
```

The `cdf()` function calculates the accumulated probability up to a given point.

In mathematical notation:

$$
P(a<X<b)=F(b)-F(a)
$$

Where $F(x)$ is the cumulative distribution function.

**Recommendation:** Use `norm.cdf()` when you need probabilities. Use `quad()` when you want to learn or implement numerical
integration.

# 4\. JavaScript implementation

We can implement numerical integration using Simpson's rule.

First, define the Gaussian PDF:

$$
f(x)=\frac{1}{\sigma\sqrt{2\pi}}
e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

### JavaScript code

javascript

```javascript
const mu = 0;
const sigma = 1;

// Gaussian probability density function
function gaussian(x) {
  return (1 / (sigma * Math.sqrt(2 * Math.PI))) * Math.exp(-Math.pow(x - mu, 2) / (2 * sigma * sigma));
}

// Simpson's numerical integration
function integrate(f, a, b, n = 10000) {
  if (n % 2 !== 0) {
    n++;
  }

  const h = (b - a) / n;

  let sum = f(a) + f(b);

  for (let i = 1; i < n; i++) {
    const x = a + i * h;

    sum += (i % 2 === 0 ? 2 : 4) * f(x);
  }

  return (h / 3) * sum;
}

// Integration limits
const a = -1;
const b = 1;

// Calculate area
const area = integrate(gaussian, a, b);

console.log("Area under Gaussian:", area);

console.log("Probability (%):", area * 100);
```

Expected output:

text

```text
Area under Gaussian: 0.682689492137...
Probability (%): 68.2689492137...
```

# 5\. TypeScript implementation

The same algorithm works in TypeScript. We can add type safety to the functions.

typescript

```typescript
const mu: number = 0;
const sigma: number = 1;

// Gaussian PDF
function gaussian(x: number): number {
  return (1 / (sigma * Math.sqrt(2 * Math.PI))) * Math.exp(-Math.pow(x - mu, 2) / (2 * sigma * sigma));
}

// Numerical integration using Simpson's rule
function integrate(f: (x: number) => number, a: number, b: number, n: number = 10000): number {
  if (n <= 0) {
    throw new Error("n must be positive");
  }

  if (n % 2 !== 0) {
    n++;
  }

  const h = (b - a) / n;

  let sum = f(a) + f(b);

  for (let i = 1; i < n; i++) {
    const x = a + i * h;

    sum += (i % 2 === 0 ? 2 : 4) * f(x);
  }

  return (h / 3) * sum;
}

// Calculate area between -1 and 1
const area: number = integrate(gaussian, -1, 1);

console.log("Gaussian area:", area);

console.log("Probability:", (area * 100).toFixed(4) + "%");
```

# 6\. Understanding the area: 68–95–99.7 rule

For a normal distribution, these are some important probability intervals:

| Interval                       | Area (probability) |
| ------------------------------ | ------------------ |
| $\mu-\sigma$ to $\mu+\sigma$   | 68.27%             |
| $\mu-2\sigma$ to $\mu+2\sigma$ | 95.45%             |
| $\mu-3\sigma$ to $\mu+3\sigma$ | 99.73%             |
| $-\infty$ to $+\infty$         | 100%               |

For example, if:

$$
\mu=100,\qquad \sigma=15
$$

Then approximately 68.27% of observations lie between:

$$
85<X<115
$$

You can calculate this in Python:

python

```python
from scipy.stats import norm

mu = 100
sigma = 15

area = norm.cdf(115, mu, sigma) - norm.cdf(85, mu, sigma)

print(f"Probability: {area * 100:.2f}%")
```

Output:

text

```text
Probability: 68.27%
```

# 7\. Visualizing the Gaussian distribution

You can also plot the Gaussian curve and highlight the integrated area using Matplotlib.

python

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

mu = 0
sigma = 1

x = np.linspace(-4, 4, 1000)

y = norm.pdf(x, mu, sigma)

a = -1
b = 1

plt.figure(figsize=(10, 6))

# Plot Gaussian distribution
plt.plot(x, y, color="blue", label="Gaussian PDF")

# Highlight integrated area
mask = (x >= a) & (x <= b)

plt.fill_between(
    x[mask],
    y[mask],
    color="orange",
    alpha=0.5,
    label="Area between -1 and 1"
)

# Calculate probability
area = norm.cdf(b, mu, sigma) - norm.cdf(a, mu, sigma)

plt.title(f"Gaussian Distribution (Area = {area:.4f})")

plt.xlabel("x")
plt.ylabel("Probability Density")

plt.legend()
plt.grid(True)

plt.show()
```

## 8\. Python vs JavaScript/TypeScript: My recommendation

| Requirement           | Python                   | JavaScript/TypeScript                        |
| --------------------- | ------------------------ | -------------------------------------------- |
| Gaussian PDF          | `scipy.stats.norm.pdf()` | Custom function                              |
| Gaussian CDF          | `scipy.stats.norm.cdf()` | Numerical integration or statistical library |
| Numerical integration | `scipy.integrate.quad()` | Simpson's rule                               |
| Plotting              | Matplotlib               | Plotly.js                                    |
| Statistical analysis  | SciPy                    | math.js / statistical libraries              |

**One important distinction:** The PDF gives you the height of the Gaussian curve, not the probability itself. To calculate
probability, you must integrate the PDF over an interval.

For most statistical applications, I recommend SciPy in Python. For interactive browser-based applications, TypeScript with
Plotly.js is an excellent combination.
