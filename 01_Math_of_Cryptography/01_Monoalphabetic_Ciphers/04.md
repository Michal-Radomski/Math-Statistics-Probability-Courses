An **additive cipher** (often called a **shift cipher**) is a type of substitution cipher where each letter of the alphabet
is shifted forward by a fixed number of positions using **modular arithmetic**.

In fact, the **Caesar shift** you learned about earlier is just a specific, famous example of an additive cipher where the
shift key is always 3.

---

### How Additive Ciphers Work Mathematically

To use an additive cipher, we first convert the alphabet into numbers, usually from **0 to 25**:

- $A = 0, B = 1, C = 2, \dots, Z = 25$

The encryption and decryption processes use modular arithmetic modulo 26 (since there are 26 letters in the English
alphabet):

1. **Encryption Formula:**

$$E(x) = (x + k) \pmod{26}$$

_(Where $x$ is the numerical value of the plaintext letter, and $k$ is the secret key/shift value)._ 2. **Decryption
Formula:**

$$D(x) = (x - k) \pmod{26}$$

_(To decode, you subtract the key instead of adding)._

---

### Step-by-Step Example

Let's encrypt the word **"CAT"** using an additive cipher with a key of **$k = 5$**.

1. **Convert letters to numbers:**

- $C = 2$
- $A = 0$
- $T = 19$

2. **Apply the encryption formula $(x + 5) \pmod{26}$:**

- For $C$: $(2 + 5) \pmod{26} = 7 \rightarrow \textbf{H}$
- For $A$: $(0 + 5) \pmod{26} = 5 \rightarrow \textbf{F}$
- For $T$: $(19 + 5) \pmod{26} = 24 \rightarrow \textbf{Y}$

3. **Ciphertext:** **HFY**

---

### Why Are They Called "Additive"?

They are called additive because the core operation is literally **adding** a constant value to every character. Because
addition modulo 26 is cyclical and symmetric, reversing the process is as simple as subtracting the same value (or adding
$26 - k$).

While additive ciphers are historically important for showing how early cryptography worked, they are trivially easy to break
today because there are only **25 possible keys** to test—a computer can test all of them in a fraction of a millisecond
using a simple brute-force attack.
