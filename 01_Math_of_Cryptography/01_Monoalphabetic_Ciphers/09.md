Here is a clean, efficient TypeScript implementation of the **Euclidean algorithm** using an iterative approach (which is
ideal because it avoids recursion depth limits when working with massive numbers).

---

### TypeScript Implementation

```typescript
/**
 * Calculates the Greatest Common Divisor (GCD) of two integers
 * using the iterative Euclidean algorithm.
 *
 * @param a - The first integer
 * @param b - The second integer
 * @returns The greatest common divisor of a and b
 */
function gcd(a: number, b: number): number {
  // Work with absolute values to handle negative numbers safely
  let x = Math.abs(a);
  let y = Math.abs(b);

  // Repeatedly take the remainder until y becomes 0
  while (y !== 0) {
    const remainder = x % y;
    x = y;
    y = remainder;
  }

  return x;
}

// --- Example Usage ---
const num1 = 252;
const num2 = 105;

const result = gcd(num1, num2);
console.log(`The GCD of ${num1} and ${num2} is: ${result}`);
// Output: The GCD of 252 and 105 is: 21
```

### Alternative: Recursive Version

The Euclidean algorithm can also be written compactly using recursion, mirroring the mathematical definition
$\text{GCD}(a, b) = \text{GCD}(b, a \pmod b)$:

```typescript
function gcdRecursive(a: number, b: number): number {
  let x = Math.abs(a);
  let y = Math.abs(b);

  if (y === 0) {
    return x;
  }
  return gcdRecursive(y, x % y);
}
```
