Here is a simple implementation of the **Diffie-Hellman key exchange algorithm in TypeScript**, using only mathematical
calculations. No Node.js imports or external libraries are required.

## 1\. Diffie-Hellman implementation

typescript

```typescript
// Calculates (base ^ exponent) % modulus
function modPow(base: number, exponent: number, modulus: number): number {
  let result = 1;

  base = base % modulus;

  while (exponent > 0) {
    if (exponent % 2 === 1) {
      result = (result * base) % modulus;
    }

    exponent = Math.floor(exponent / 2);
    base = (base * base) % modulus;
  }

  return result;
}

// Generates public and private keys
function generateKeys(privateKey: number, generator: number, prime: number) {
  const publicKey = modPow(generator, privateKey, prime);

  return {
    privateKey,
    publicKey,
  };
}

// Calculates shared secret
function calculateSharedSecret(otherPublicKey: number, privateKey: number, prime: number): number {
  return modPow(otherPublicKey, privateKey, prime);
}
```

## 2\. Example with small numbers

Let's simulate two people: Alice and Bob.

They agree on two public parameters:

- Prime number: `23`
- Generator: `5`

typescript

```typescript
const prime = 23;
const generator = 5;

// Alice chooses her private key
const alice = generateKeys(6, generator, prime);

// Bob chooses his private key
const bob = generateKeys(15, generator, prime);

// Exchange public keys and calculate shared secrets
const aliceSecret = calculateSharedSecret(bob.publicKey, alice.privateKey, prime);

const bobSecret = calculateSharedSecret(alice.publicKey, bob.privateKey, prime);

console.log("Alice public key:", alice.publicKey);
console.log("Bob public key:", bob.publicKey);

console.log("Alice shared secret:", aliceSecret);
console.log("Bob shared secret:", bobSecret);
```

## 3\. Expected output

text

```text
Alice public key: 8
Bob public key: 19

Alice shared secret: 2
Bob shared secret: 2
```

## 4\. How does it work?

Let's break down the calculations.

**Step 1: Alice generates her public key**

Alice's private key is `6`.

text

```text
A = 5^6 mod 23
A = 15625 mod 23
A = 8
```

**Step 2: Bob generates his public key**

Bob's private key is `15`.

text

```text
B = 5^15 mod 23
B = 19
```

**Step 3: They exchange public keys**

- Alice receives Bob's public key: `19`.
- Bob receives Alice's public key: `8`.

**Step 4: Both calculate the shared secret**

Alice calculates:

text

```text
S = 19^6 mod 23
S = 2
```

Bob calculates:

text

```text
S = 8^15 mod 23
S = 2
```

Both arrive at the same secret:

text

```text
Alice secret === Bob secret
2 === 2
```

## 5\. Why does this work?

The mathematical principle behind Diffie-Hellman is:

text

```text
A = g^a mod p
B = g^b mod p
```

Where:

- `g` = generator
- `p` = prime number
- `a` = Alice's private key
- `b` = Bob's private key

Alice calculates:

text

```text
S = B^a mod p
```

Bob calculates:

text

```text
S = A^b mod p
```

Because of exponentiation rules:

text

```text
(g^b)^a = (g^a)^b
```

Therefore:

text

```text
S = g^(a*b) mod p
```

Both get exactly the same result without ever exchanging their private keys.

**Important:** These small numbers are only for educational purposes. JavaScript's `number` type also has precision
limitations for large modular exponentiation. For real cryptographic applications, use `BigInt` and a vetted cryptographic
implementation with secure parameter choices. Also, Diffie-Hellman alone does not authenticate participants, so it is
vulnerable to man-in-the-middle attacks.
