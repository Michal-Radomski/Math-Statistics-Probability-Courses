Here is a simple implementation of **RSA encryption and decryption in TypeScript**, using only mathematical calculations. No
Node.js imports or external libraries are required.

We'll use small numbers to make the calculations easy to understand.

## 1\. RSA implementation in TypeScript

RSA uses two keys:

- **Public key:** Used to encrypt messages.
- **Private key:** Used to decrypt messages.

typescript

```typescript
// Calculates (base ^ exponent) % modulus
function modPow(base: number, exponent: number, modulus: number): number {
  let result = 1;

  base = base % modulus;

  while (exponent > 0) {
    if (exponent % 2 === 1) {
      result = (result * base) % modulus;
    }

    exponent = Math.floor(exponent / 2);
    base = (base * base) % modulus;
  }

  return result;
}

// Calculates the greatest common divisor
function gcd(a: number, b: number): number {
  while (b !== 0) {
    const temp = b;
    b = a % b;
    a = temp;
  }

  return a;
}

// Finds modular multiplicative inverse
function modInverse(e: number, phi: number): number {
  for (let d = 1; d < phi; d++) {
    if ((e * d) % phi === 1) {
      return d;
    }
  }

  throw new Error("Modular inverse not found");
}

// Generates RSA keys
function generateRSAKeys(p: number, q: number) {
  const n = p * q;
  const phi = (p - 1) * (q - 1);

  // Choose public exponent
  let e = 3;

  while (gcd(e, phi) !== 1) {
    e += 2;
  }

  // Calculate private exponent
  const d = modInverse(e, phi);

  return {
    publicKey: { e, n },
    privateKey: { d, n },
  };
}

// Encrypts a numeric message
function encrypt(message: number, publicKey: { e: number; n: number }): number {
  return modPow(message, publicKey.e, publicKey.n);
}

// Decrypts a numeric message
function decrypt(ciphertext: number, privateKey: { d: number; n: number }): number {
  return modPow(ciphertext, privateKey.d, privateKey.n);
}
```

## 2\. Example: Encrypting and decrypting a message

Let's use two small prime numbers:

typescript

```typescript
const p = 11;
const q = 13;

// Generate keys
const keys = generateRSAKeys(p, q);

console.log("Public key:", keys.publicKey);
console.log("Private key:", keys.privateKey);

// Original message
const message = 42;

// Encrypt
const encrypted = encrypt(message, keys.publicKey);

// Decrypt
const decrypted = decrypt(encrypted, keys.privateKey);

console.log("Original message:", message);
console.log("Encrypted message:", encrypted);
console.log("Decrypted message:", decrypted);
```

### Expected output

text

```text
Public key: { e: 7, n: 143 }
Private key: { d: 103, n: 143 }

Original message: 42
Encrypted message: 81
Decrypted message: 42
```

## 3\. How does RSA work mathematically?

Let's break down the example.

### Step 1: Generate keys

We choose two prime numbers:

text

```text
p = 11
q = 13
```

Calculate `n`:

text

```text
n = p * q
n = 11 * 13
n = 143
```

Calculate Euler's totient function:

text

```text
φ(n) = (p - 1) * (q - 1)

φ(n) = 10 * 12

φ(n) = 120
```

### Step 2: Calculate public key

Choose a number `e` that is relatively prime to `φ(n)`.

We choose:

text

```text
e = 7
```

Because:

text

```text
gcd(7, 120) = 1
```

Our public key is:

text

```text
(e, n) = (7, 143)
```

### Step 3: Calculate private key

We need to find `d` such that:

text

```text
(e * d) mod φ(n) = 1
```

In our example:

text

```text
(7 * 103) mod 120 = 1

d = 103
```

Our private key is:

text

```text
(d, n) = (103, 143)
```

### Step 4: Encrypt the message

Let's encrypt the number `42`.

The RSA encryption formula is:

text

```text
C = M^e mod n
```

Where:

- `M` = original message
- `e` = public exponent
- `n` = modulus
- `C` = encrypted message

Substituting:

text

```text
C = 42^7 mod 143

C = 81
```

The encrypted message is `81`.

### Step 5: Decrypt the message

The RSA decryption formula is:

text

```text
M = C^d mod n
```

Substituting:

text

```text
M = 81^103 mod 143

M = 42
```

We successfully recovered the original message\!

## 4\. RSA vs. Diffie-Hellman

Both algorithms use modular arithmetic, but their purposes are different.

| Feature          | Diffie-Hellman | RSA                     |
| ---------------- | -------------- | ----------------------- |
| Main purpose     | Key exchange   | Encryption / signatures |
| Public key       | Yes            | Yes                     |
| Private key      | Yes            | Yes                     |
| Exchange secret  | Yes            | No                      |
| Encrypt messages | Not directly   | Yes                     |
| Decrypt messages | Not directly   | Yes                     |

**One important security note:** This implementation is strictly educational. Small primes, JavaScript `number` arithmetic,
and textbook RSA are not secure. Real RSA encryption should use a vetted library implementing RSA-OAEP with secure key sizes
(typically 2048 bits or more). Never use this implementation to protect real messages.
