In probability and statistics, a **uniform distribution** is the simplest type of probability distribution. It describes a
situation where **every possible outcome is equally likely** to occur.

If you were to graph a uniform distribution, it looks completely flat—like a straight horizontal line or a flat
rectangle—which is why it is sometimes called a **rectangular distribution**.

There are two main types of uniform distributions: **Discrete** and **Continuous**.

---

### 1. Discrete Uniform Distribution

A discrete uniform distribution happens when there is a finite number of distinct, individual outcomes, and each has the
exact same probability.

- **Classic Example:** Rolling a fair 6-sided die. Each number ($1, 2, 3, 4, 5, 6$) has an equal chance of appearing.
- **The Formula:** If there are $n$ possible outcomes, the probability $P(X)$ of any single outcome occurring is:

$$P(X) = \frac{1}{n}$$

_(For a fair die, $n = 6$, so the probability of rolling any specific number is $\frac{1}{6}$.)_

---

### 2. Continuous Uniform Distribution

A continuous uniform distribution applies when values can fall anywhere within a continuous range (an interval) between a
minimum value ($a$) and a maximum value ($b$), and every sub-interval of equal length has an equal probability.

- **Classic Example:** Waiting for a bus that arrives uniformly and randomly anytime between 0 and 10 minutes ($a = 0$,
  $b = 10$). The chance of the bus arriving in any 2-minute window (like minute 3 to 5) is the exact same as any other
  2-minute window.
- **Probability Density Function (PDF):** Instead of a single point having probability, continuous distributions use a curve
  where height represents probability density. For a uniform distribution between $a$ and $b$, the height is constant:

$$f(x) = \frac{1}{b - a} \quad \text{for } a \le x \le b$$

- **Expected Value (Mean):** The average or expected outcome sits right in the middle of the range:

$$\mu = \frac{a + b}{2}$$

---

### Summary Comparison

| Feature                  | Discrete Uniform                                      | Continuous Uniform                                             |
| ------------------------ | ----------------------------------------------------- | -------------------------------------------------------------- |
| **Outcomes**             | Distinct countable values (e.g., die roll, coin flip) | An unbroken range of real numbers (e.g., time, weight, length) |
| **Probability Function** | $P(X) = \frac{1}{n}$                                  | $f(x) = \frac{1}{b - a}$                                       |
| **Visual Shape**         | A series of equal-height bars (histogram)             | A flat, continuous horizontal line forming a rectangle         |
