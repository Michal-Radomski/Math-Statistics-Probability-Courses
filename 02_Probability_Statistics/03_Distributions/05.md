In TypeScript, you can calculate the **Normal Distribution (Gaussian Distribution)** using mathematical formulas.

There are three important calculations worth implementing:

1. Probability Density Function (PDF).
2. Cumulative Distribution Function (CDF).
3. Z-score (Standard Score).

Let's implement all three.

# 1\. Understanding Normal Distribution

A normal distribution is a probability distribution shaped like a bell curve.

It is defined by two parameters:

- **Mean (μ):** Determines the center of the distribution.
- **Standard deviation (σ):** Determines how spread out the distribution is.

Example:

Imagine exam scores follow a normal distribution:

typescript

```typescript
const mean = 70;
const standardDeviation = 10;
```

This means:

- Average exam score = 70.
- Standard deviation = 10.
- Most students score relatively close to 70.

z=x−μσz = \\frac{x - \\mu}{\\sigma}

# 2\. Probability Density Function (PDF)

PDF calculates the probability density at a particular value.

The formula is:

$$
f(x)=\frac{1}{\sigma\sqrt{2\pi}}
e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

Where:

- `x` = Value we want to evaluate.
- `μ` = Mean.
- `σ` = Standard deviation.
- `π` = Pi.
- `e` = Euler's number.

### TypeScript implementation

typescript

```typescript
function normalPDF(x: number, mean: number, standardDeviation: number): number {
  if (standardDeviation <= 0) {
    throw new Error("Standard deviation must be positive");
  }

  const exponent = -Math.pow(x - mean, 2) / (2 * Math.pow(standardDeviation, 2));

  return (1 / (standardDeviation * Math.sqrt(2 * Math.PI))) * Math.exp(exponent);
}
```

Example:

typescript

```typescript
console.log(normalPDF(70, 70, 10));
```

Output:

text

```text
0.039894228
```

**Important:** PDF does not directly calculate the probability of getting exactly 70. It calculates probability density. To
calculate probabilities over an interval, use CDF.

# 3\. Cumulative Distribution Function (CDF)

CDF calculates the probability that a random variable is less than or equal to a particular value.

Mathematically:

$$
F(x)=P(X\leq x)
$$

For example:

What is the probability that a student scores 80 or less?

$$
P(X\leq80)
$$

### TypeScript implementation

JavaScript doesn't have a built-in error function (`erf`), so we need to implement an approximation.

typescript

```typescript
function erf(x: number): number {
  const sign = x < 0 ? -1 : 1;
  x = Math.abs(x);

  const a1 = 0.254829592;
  const a2 = -0.284496736;
  const a3 = 1.421413741;
  const a4 = -1.453152027;
  const a5 = 1.061405429;
  const p = 0.3275911;

  const t = 1 / (1 + p * x);

  const y = 1 - ((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t * Math.exp(-x * x);

  return sign * y;
}

function normalCDF(x: number, mean: number, standardDeviation: number): number {
  if (standardDeviation <= 0) {
    throw new Error("Standard deviation must be positive");
  }

  const z = (x - mean) / (standardDeviation * Math.sqrt(2));

  return 0.5 * (1 + erf(z));
}
```

Example:

typescript

```typescript
console.log(normalCDF(80, 70, 10));
```

Output (approximately):

text

```text
0.8413447
```

This means:

**Approximately 84.13% of students score 80 or less.**

# 4\. Z-score (Standard Score)

A Z-score tells us how many standard deviations a value is away from the mean.

Formula:

$$
z=\frac{x-\mu}{\sigma}
$$

### TypeScript implementation

typescript

```typescript
function zScore(x: number, mean: number, standardDeviation: number): number {
  if (standardDeviation <= 0) {
    throw new Error("Standard deviation must be positive");
  }

  return (x - mean) / standardDeviation;
}
```

Example:

typescript

```typescript
console.log(zScore(80, 70, 10));
```

Output:

text

```text
1
```

Interpretation:

A score of 80 is exactly **one standard deviation above the mean**.

# 5\. The 68–95–99.7 Rule

One of the most important properties of normal distributions is the empirical rule.

| Interval | Percentage of observations |
| -------- | -------------------------- |
| μ ± 1σ   | 68.27%                     |
| μ ± 2σ   | 95.45%                     |
| μ ± 3σ   | 99.73%                     |

For our example:

- Mean = 70.
- Standard deviation = 10.

| Score interval | Approximate percentage |
| -------------- | ---------------------- |
| 60–80          | 68.27%                 |
| 50–90          | 95.45%                 |
| 40–100         | 99.73%                 |

# 6\. Complete TypeScript implementation

You can combine everything into a reusable utility:

typescript

```typescript
function factorial(n: number): bigint {
  if (!Number.isInteger(n) || n < 0) {
    throw new Error("Invalid factorial argument");
  }

  let result = 1n;

  for (let i = 2; i <= n; i++) {
    result *= BigInt(i);
  }

  return result;
}

function normalPDF(x: number, mean: number, sd: number): number {
  validateSD(sd);

  const exponent = -((x - mean) ** 2) / (2 * sd ** 2);

  return Math.exp(exponent) / (sd * Math.sqrt(2 * Math.PI));
}

function erf(x: number): number {
  const sign = x < 0 ? -1 : 1;
  x = Math.abs(x);

  const p = 0.3275911;
  const a1 = 0.254829592;
  const a2 = -0.284496736;
  const a3 = 1.421413741;
  const a4 = -1.453152027;
  const a5 = 1.061405429;

  const t = 1 / (1 + p * x);

  const result = 1 - ((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t * Math.exp(-x * x);

  return sign * result;
}

function normalCDF(x: number, mean: number, sd: number): number {
  validateSD(sd);

  const z = (x - mean) / (sd * Math.sqrt(2));

  return 0.5 * (1 + erf(z));
}

function zScore(x: number, mean: number, sd: number): number {
  validateSD(sd);

  return (x - mean) / sd;
}

function validateSD(sd: number): void {
  if (!Number.isFinite(sd) || sd <= 0) {
    throw new Error("Standard deviation must be positive");
  }
}

// Example
const mean = 70;
const sd = 10;
const x = 80;

console.log("PDF:", normalPDF(x, mean, sd));
console.log("CDF:", normalCDF(x, mean, sd));
console.log("Z-score:", zScore(x, mean, sd));
```

Expected output:

```text

CDF: 0.841344...
Z-score: 1
```

# 7\. Summary: What should you use?

| Function      | Purpose                            | Example                 |
| ------------- | ---------------------------------- | ----------------------- |
| `normalPDF()` | Probability density at a value     | Density at 80           |
| `normalCDF()` | Probability of being below a value | P(X ≤ 80)               |
| `zScore()`    | Standardize a value                | How many SDs from mean? |

**One important distinction:**

- Use PDF when you need the density of a distribution.
- Use CDF when you need probabilities.
- Use Z-score when you need to compare observations relative to a standard normal distribution.

It lets you calculate the value corresponding to a given probability, for example, finding the exam score that separates the
top 5% of students from everyone else.
