You can draw a Normal Distribution (Gaussian/Bell Curve) in a React application using **Recharts**.

I'll show you how to:

1. Install Recharts.
2. Generate points for a normal distribution.
3. Calculate the probability density (PDF).
4. Render a bell curve.
5. Display the mean and standard deviation.
6. Optionally highlight the area between two values.

## 1\. Install Recharts

bash

```bash
npm install recharts
```

Recharts is a React charting library built on top of D3.

## 2\. Create the Normal Distribution calculation

First, implement the Probability Density Function (PDF):

typescript

```typescript
export function normalPDF(x: number, mean: number, standardDeviation: number): number {
  const exponent = -Math.pow(x - mean, 2) / (2 * Math.pow(standardDeviation, 2));

  return (1 / (standardDeviation * Math.sqrt(2 * Math.PI))) * Math.exp(exponent);
}
```

This function calculates the height of the bell curve for a given X value.

## 3\. Generate chart data

We need to generate multiple points to draw a smooth curve.

typescript

```typescript
type DistributionPoint = {
  x: number;
  y: number;
};

export function generateNormalDistribution(mean: number, standardDeviation: number, points = 200): DistributionPoint[] {
  if (standardDeviation <= 0) {
    throw new Error("Standard deviation must be positive");
  }

  const start = mean - 4 * standardDeviation;
  const end = mean + 4 * standardDeviation;

  const step = (end - start) / (points - 1);

  return Array.from({ length: points }, (_, index) => {
    const x = start + index * step;

    return {
      x,
      y: normalPDF(x, mean, standardDeviation),
    };
  });
}
```

For example:

typescript

```typescript
const data = generateNormalDistribution(70, 10);
```

This generates 200 points between:

text

```text
Minimum: 30
Maximum: 110
```

Each point contains:

typescript

```typescript
{
    x: 70,
    y: 0.03989
}
```

## 4\. Create the React component

Now let's create the actual chart.

tsx

```tsx
import { LineChart, Line, XAxis, YAxis, CartesianGrid, Tooltip, ResponsiveContainer, ReferenceLine } from "recharts";

import { generateNormalDistribution } from "./statistics";

type NormalDistributionChartProps = {
  mean: number;
  standardDeviation: number;
};

export function NormalDistributionChart({ mean, standardDeviation }: NormalDistributionChartProps) {
  const data = generateNormalDistribution(mean, standardDeviation);

  return (
    <div style={{ width: "100%", height: 400 }}>
      <ResponsiveContainer width="100%" height="100%">
        <LineChart data={data}>
          <CartesianGrid strokeDasharray="3 3" />

          <XAxis
            dataKey="x"
            type="number"
            domain={["dataMin", "dataMax"]}
            label={{
              value: "Value",
              position: "insideBottom",
              offset: -5,
            }}
          />

          <YAxis
            label={{
              value: "Probability Density",
              angle: -90,
              position: "insideLeft",
            }}
          />

          <Tooltip formatter={(value) => Number(value).toFixed(5)} />

          <ReferenceLine x={mean} stroke="red" strokeDasharray="5 5" label="Mean" />

          <Line type="monotone" dataKey="y" stroke="#2563eb" strokeWidth={3} dot={false} isAnimationActive={false} />
        </LineChart>
      </ResponsiveContainer>
    </div>
  );
}
```

## 5\. Use the component

tsx

```tsx
export default function App() {
  return (
    <div>
      <h1>Normal Distribution</h1>

      <NormalDistributionChart mean={70} standardDeviation={10} />
    </div>
  );
}
```

You should now see a bell-shaped curve centered at 70.

## 6\. Understanding the chart

For our example:

- Mean = 70
- Standard deviation = 10

The distribution looks approximately like this:

### Important statistical reference points

You can also add vertical reference lines to visualize standard deviations.

| Position | Value | Percentage within interval |
| -------- | ----- | -------------------------- |
| μ - 3σ   | 40    |                            |
| μ - 2σ   | 50    |                            |
| μ - 1σ   | 60    |                            |
| μ        | 70    | 68.27% within ±1σ          |
| μ + 1σ   | 80    |                            |
| μ + 2σ   | 90    | 95.45% within ±2σ          |
| μ + 3σ   | 100   | 99.73% within ±3σ          |

For example, add these to your Recharts component:

tsx

```tsx
<ReferenceLine x={mean - standardDeviation} stroke="orange" />
<ReferenceLine x={mean + standardDeviation} stroke="orange" />

<ReferenceLine x={mean - 2 * standardDeviation} stroke="green" />
<ReferenceLine x={mean + 2 * standardDeviation} stroke="green" />

<ReferenceLine x={mean - 3 * standardDeviation} stroke="gray" />
<ReferenceLine x={mean + 3 * standardDeviation} stroke="gray" />
```

## 7\. My recommendation: Make it interactive

If you're building a statistics application, I'd make the chart interactive.

For example, allow users to change:

- Mean (μ).
- Standard deviation (σ).
- X value.
- Lower and upper bounds.

Then display dynamically:

| Statistic          | Value  |
| ------------------ | ------ |
| Mean               | 70     |
| Standard deviation | 10     |
| Variance           | 100    |
| P(X ≤ 80)          | 84.13% |
| P(X \> 80)         | 15.87% |
| P(60 ≤ X ≤ 80)     | 68.27% |

You can use React state:

tsx

```tsx
const [mean, setMean] = useState(70);
const [sd, setSd] = useState(10);

const [x, setX] = useState(80);

const probability = normalCDF(x, mean, sd);
```

This would give you a proper interactive Normal Distribution calculator, rather than just a static chart.

**One additional suggestion:** Consider adding an `AreaChart` from Recharts. It allows you to shade the area under the normal
distribution curve between two selected values, which is particularly useful for visualizing probabilities such as P(60 ≤ X ≤
80).
