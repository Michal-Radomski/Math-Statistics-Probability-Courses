In TypeScript, you can implement **permutations, combinations, and variations** using factorials.

The important difference is whether the order of selected elements matters and whether repetition is allowed.

## 1\. Mathematical formulas

Let's use:

- `n` = Total number of available elements.
- `r` = Number of elements selected.

| Concept      | Order matters? | Repetition? |
| ------------ | -------------- | ----------- |
| Permutations | Yes            | No          |
| Combinations | No             | No          |
| Variations   | Yes            | No          |

**Permutations** (arranging all elements):

$$
P(n)=n!
$$

**Combinations** (selecting elements without considering order):

$$
C(n,r)=\frac{n!}{r!(n-r)!}
$$

**Variations** (selecting and arranging r elements from n):

$$
V(n,r)=\frac{n!}{(n-r)!}
$$

## 2\. TypeScript implementation

### Factorial function

First, create a reusable factorial function:

typescript

```typescript
function factorial(n: number): bigint {
  if (!Number.isInteger(n) || n < 0) {
    throw new Error("n must be a non-negative integer");
  }

  let result = 1n;

  for (let i = 2; i <= n; i++) {
    result *= BigInt(i);
  }

  return result;
}
```

We use `bigint` because factorials grow very quickly and can exceed JavaScript's safe integer limit.

### A. Permutations

Permutations calculate the number of possible arrangements of all elements.

typescript

```typescript
function permutations(n: number): bigint {
  return factorial(n);
}
```

Example:

typescript

```typescript
console.log(permutations(5)); // 120
```

Mathematically:

$$
5!=5\times4\times3\times2\times1=120
$$

### B. Combinations

Combinations calculate how many ways we can select `r` elements from `n`, without considering their order.

typescript

```typescript
function combinations(n: number, r: number): bigint {
  if (!Number.isInteger(n) || !Number.isInteger(r) || n < 0 || r < 0 || r > n) {
    throw new Error("Invalid n or r");
  }

  return factorial(n) / (factorial(r) * factorial(n - r));
}
```

Example:

typescript

```typescript
console.log(combinations(5, 3)); // 10
```

Mathematically:

$$
C(5,3)=\frac{5!}{3!(5-3)!}=10
$$

### C. Variations

Variations calculate how many ways we can select and arrange `r` elements from `n`.

typescript

```typescript
function variations(n: number, r: number): bigint {
  if (!Number.isInteger(n) || !Number.isInteger(r) || n < 0 || r < 0 || r > n) {
    throw new Error("Invalid n or r");
  }

  return factorial(n) / factorial(n - r);
}
```

Example:

typescript

```typescript
console.log(variations(5, 3)); // 60
```

Mathematically:

$$
V(5,3)=\frac{5!}{(5-3)!}=60
$$

## 3\. Complete implementation

Here is everything together:

typescript

```typescript
function factorial(n: number): bigint {
  if (!Number.isInteger(n) || n < 0) {
    throw new Error("Invalid factorial argument");
  }

  let result = 1n;

  for (let i = 2; i <= n; i++) {
    result *= BigInt(i);
  }

  return result;
}

// Permutations: n!
function permutations(n: number): bigint {
  return factorial(n);
}

// Combinations: n! / (r! * (n-r)!)
function combinations(n: number, r: number): bigint {
  validate(n, r);

  return factorial(n) / (factorial(r) * factorial(n - r));
}

// Variations: n! / (n-r)!
function variations(n: number, r: number): bigint {
  validate(n, r);

  return factorial(n) / factorial(n - r);
}

function validate(n: number, r: number): void {
  if (!Number.isInteger(n) || !Number.isInteger(r) || n < 0 || r < 0 || r > n) {
    throw new Error("Invalid n or r");
  }
}

// Examples
console.log("Permutations:", permutations(5).toString());
console.log("Combinations:", combinations(5, 3).toString());
console.log("Variations:", variations(5, 3).toString());
```

Output:

text

```text
Permutations: 120
Combinations: 10
Variations: 60
```

## 5\. Bonus: What about repetition?

There are also versions where elements can be selected more than once.

| Concept                         | Formula                  | Example (n=5, r=3) |
| ------------------------------- | ------------------------ | ------------------ |
| Combinations without repetition | n\! / (r\!(n-r)\!)       | 10                 |
| Combinations with repetition    | (n+r-1)\! / (r\!(n-1)\!) | 35                 |
| Variations without repetition   | n\! / (n-r)\!            | 60                 |
| Variations with repetition      | n^r                      | 125                |

For variations with repetition, you could implement:

typescript

```typescript
function variationsWithRepetition(n: number, r: number): bigint {
  if (!Number.isInteger(n) || !Number.isInteger(r) || n < 0 || r < 0) {
    throw new Error("Invalid n or r");
  }

  return BigInt(n) ** BigInt(r);
}
```

**My recommendation:** If you're building a statistics or mathematics library in TypeScript, implement all five functions.
They cover the most common counting problems in combinatorics.
