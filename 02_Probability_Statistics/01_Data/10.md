Below is a practical example using **TypeScript** to calculate the following descriptive statistics:

1. Mean
2. Median
3. Mode
4. Standard deviation
5. Variance
6. Range
7. Quartiles (Q1, Q2, Q3)
8. Interquartile Range (IQR)

## 1\. Example dataset

Let's use a dataset representing the exam scores of 10 students:

typescript

```typescript
const data: number[] = [12, 15, 18, 18, 20, 22, 25, 28, 30, 32];
```

First, sort the dataset:

text

```text
[12, 15, 18, 18, 20, 22, 25, 28, 30, 32]
```

## 2\. TypeScript implementation

Here is a complete implementation:

typescript

```typescript
function calculateStatistics(data: number[]) {
  if (data.length === 0) {
    throw new Error("Dataset cannot be empty");
  }

  const sorted = [...data].sort((a, b) => a - b);
  const n = sorted.length;

  // Mean
  const mean = sorted.reduce((sum, value) => sum + value, 0) / n;

  // Median
  function median(values: number[]): number {
    const length = values.length;
    const middle = Math.floor(length / 2);

    if (length % 2 === 0) {
      return (values[middle - 1] + values[middle]) / 2;
    }

    return values[middle];
  }

  const medianValue = median(sorted);

  // Mode
  const frequency = new Map<number, number>();

  sorted.forEach((value) => {
    frequency.set(value, (frequency.get(value) ?? 0) + 1);
  });

  const maxFrequency = Math.max(...frequency.values());

  const mode =
    maxFrequency > 1 ? [...frequency.entries()].filter(([_, count]) => count === maxFrequency).map(([value]) => value) : [];

  // Variance (Population)
  const variance = sorted.reduce((sum, value) => sum + Math.pow(value - mean, 2), 0) / n;

  // Standard deviation (Population)
  const standardDeviation = Math.sqrt(variance);

  // Range
  const range = sorted[n - 1] - sorted[0];

  // Quartiles
  const middle = Math.floor(n / 2);

  const lowerHalf = sorted.slice(0, middle);
  const upperHalf = sorted.slice(n % 2 === 0 ? middle : middle + 1);

  const Q1 = median(lowerHalf);
  const Q2 = medianValue;
  const Q3 = median(upperHalf);

  // Interquartile Range
  const IQR = Q3 - Q1;

  return {
    mean,
    median: medianValue,
    mode,
    variance,
    standardDeviation,
    range,
    quartiles: {
      Q1,
      Q2,
      Q3,
    },
    IQR,
  };
}

// Example usage
const data: number[] = [12, 15, 18, 18, 20, 22, 25, 28, 30, 32];

const results = calculateStatistics(data);

console.log(results);
```

## 4\. Understanding each calculation

Let's understand what each statistic actually measures.

### Mean (Average)

The sum of all values divided by the number of values.

$$
Mean = \frac{\sum x_i}{n}
$$

Example:

$$
\frac{12+15+18+18+20+22+25+28+30+32}{10}=22
$$

### Median

The middle value of a sorted dataset.

Because we have 10 values (an even number), we calculate the average of the two middle values:

$$
Median = \frac{20+22}{2}=21
$$

### Mode

The value that appears most frequently.

In our dataset:

- 18 appears twice.
- All other values appear once.

Therefore:

$$
Mode = 18
$$

### Variance

Measures how spread out the values are from the mean.

$$
Variance = \frac{\sum(x_i-\mu)^2}{n}
$$

Here, we use population variance, dividing by $n$.

Result:

$$
Variance = 37.6
$$

### Standard deviation

Measures how far values typically spread from the mean.

It is the square root of variance.

$$
SD = \sqrt{Variance}
$$

$$
SD = \sqrt{37.6} \approx 6.13
$$

σ=1N∑i=1N(xi−μ)2\\sigma = \\sqrt{\\frac{1}{N}\\sum\_{i=1}^{N}(x_i-\\mu)^2}

### Range

The difference between the largest and smallest values.

$$
Range = Max - Min
$$

$$
Range = 32-12=20
$$

### Quartiles

Quartiles divide a sorted dataset into four sections.

- **Q1:** First quartile (25%).
- **Q2:** Second quartile (50%), equivalent to the median.
- **Q3:** Third quartile (75%).

For our dataset:

text

```text
[12, 15, 18, 18, 20] | [22, 25, 28, 30, 32]
```

- Q1 = Median of lower half = 18
- Q2 = Median of entire dataset = 21
- Q3 = Median of upper half = 28

### Interquartile Range (IQR)

Measures the spread of the middle 50% of the dataset.

$$
IQR = Q3-Q1
$$

$$
IQR = 28-18=10
$$

IQR is particularly useful for identifying outliers.

A common outlier detection method uses:

$$
LowerBound = Q1-1.5(IQR)
$$

$$
UpperBound = Q3+1.5(IQR)
$$

For our dataset:

- Lower bound = 3
- Upper bound = 43

Values outside these boundaries are potential outliers.

---

## 5\. Important: Population vs. Sample statistics

There are two ways to calculate variance and standard deviation.

| Statistic          | Population           | Sample           |
| ------------------ | -------------------- | ---------------- |
| Variance           | Divide by n          | Divide by n - 1  |
| Standard deviation | √Population variance | √Sample variance |

In our implementation, we use **population variance**.

If your dataset represents a sample rather than an entire population, change:

typescript

```typescript
const variance = sumOfSquaredDifferences / n;
```

To:

typescript

```typescript
const variance = sumOfSquaredDifferences / (n - 1);
```

And calculate standard deviation using the square root of that variance.

**One final note:** Quartile calculation methods can differ between statistical libraries. This example uses the
median-of-halves method (also known as the Tukey method).

For consistency, make sure you use the same quartile convention throughout your project.
