Let's build a practical example in **TypeScript** to calculate:

1. Bivariate Data

We'll use a dataset representing the relationship between **hours studied and exam scores**.

# 1\. Bivariate Data

Bivariate data means we collect observations for **two variables** for each individual or object.

For example:

- Variable X: Hours studied.
- Variable Y: Exam score.

Our dataset:

| Student | Hours studied (X) | Exam score (Y) |
| ------- | ----------------- | -------------- |
| A       | 1                 | 50             |
| B       | 2                 | 55             |
| C       | 3                 | 65             |
| D       | 4                 | 70             |
| E       | 5                 | 80             |

In TypeScript, we can represent this using an array of objects:

typescript

```typescript
type Observation = {
  x: number;
  y: number;
};

const data: Observation[] = [
  { x: 1, y: 50 },
  { x: 2, y: 55 },
  { x: 3, y: 65 },
  { x: 4, y: 70 },
  { x: 5, y: 80 },
];
```

Each observation contains two related values.

# 2\. Covariance

Covariance measures whether two variables tend to change together.

There are three possible interpretations:

| Covariance           | Meaning                                          |
| -------------------- | ------------------------------------------------ |
| Positive             | Both variables tend to increase together.        |
| Negative             | When one increases, the other tends to decrease. |
| Zero (approximately) | No linear tendency to change together.           |

### Formula

For population covariance:

$$
Cov(X,Y)=\frac{\sum(X_i-\bar X)(Y_i-\bar Y)}{n}
$$

Where:

- $X_i$: Individual X value.
- $Y_i$: Individual Y value.
- $\bar X$: Mean of X.
- $\bar Y$: Mean of Y.
- $n$: Number of observations.

### TypeScript implementation

typescript

```typescript
function calculateCovariance(data: Observation[]): number {
  const n = data.length;

  if (n === 0) {
    throw new Error("Dataset cannot be empty");
  }

  const meanX = data.reduce((sum, item) => sum + item.x, 0) / n;

  const meanY = data.reduce((sum, item) => sum + item.y, 0) / n;

  const covariance =
    data.reduce((sum, item) => {
      return sum + (item.x - meanX) * (item.y - meanY);
    }, 0) / n;

  return covariance;
}
```

### Let's calculate it manually

First, calculate the means:

$$
\bar X = \frac{1+2+3+4+5}{5}=3
$$

$$
\bar Y = \frac{50+55+65+70+80}{5}=64
$$

Now calculate the deviations:

| X   | Y   | X - Mean X | Y - Mean Y | Product |
| --- | --- | ---------- | ---------- | ------- |
| 1   | 50  | -2         | -14        | 28      |
| 2   | 55  | -1         | -9         | 9       |
| 3   | 65  | 0          | 1          | 0       |
| 4   | 70  | 1          | 6          | 6       |
| 5   | 80  | 2          | 16         | 32      |
|     |     |            | **Sum**    | **75**  |

Therefore:

$$
Cov(X,Y)=\frac{75}{5}=15
$$

**Result: Covariance = 15**

Since covariance is positive, the variables tend to increase together.

# 3\. Pearson Correlation Coefficient

Pearson correlation measures the **strength and direction of a linear relationship** between two variables.

Unlike covariance, Pearson correlation is standardized and always falls between -1 and +1.

### Formula

$$
r = \frac{Cov(X,Y)}{\sigma_X \cdot \sigma_Y}
$$

Where:

- $Cov(X,Y)$: Covariance.
- $\sigma_X$: Standard deviation of X.
- $\sigma_Y$: Standard deviation of Y.

### Interpretation

| Correlation (r) | Interpretation               |
| --------------- | ---------------------------- |
| +1              | Perfect positive correlation |
| +0.7            | Strong positive correlation  |
| +0.3            | Weak positive correlation    |
| 0               | No linear correlation        |
| -0.3            | Weak negative correlation    |
| -0.7            | Strong negative correlation  |
| -1              | Perfect negative correlation |

### TypeScript implementation

typescript

```typescript
function calculatePearsonCorrelation(data: Observation[]): number {
  const n = data.length;

  if (n < 2) {
    throw new Error("At least two observations are required");
  }

  const meanX = data.reduce((sum, item) => sum + item.x, 0) / n;

  const meanY = data.reduce((sum, item) => sum + item.y, 0) / n;

  let numerator = 0;
  let sumSquaredX = 0;
  let sumSquaredY = 0;

  for (const item of data) {
    const dx = item.x - meanX;
    const dy = item.y - meanY;

    numerator += dx * dy;

    sumSquaredX += dx * dx;
    sumSquaredY += dy * dy;
  }

  const denominator = Math.sqrt(sumSquaredX * sumSquaredY);

  if (denominator === 0) {
    throw new Error("Correlation is undefined when a variable has zero variance");
  }

  return numerator / denominator;
}
```

### Result

For our dataset:

$$
r = \frac{75}{\sqrt{10 \cdot 570}}
$$

$$
r \approx 0.9934
$$

**Result: Pearson correlation ≈ 0.9934**

This indicates a very strong positive linear relationship between hours studied and exam scores.

# 4\. Complete TypeScript implementation

You can combine everything into one reusable function:

typescript

```typescript
type Observation = {
  x: number;
  y: number;
};

function calculateBivariateStatistics(data: Observation[]) {
  const n = data.length;

  if (n < 2) {
    throw new Error("At least two observations are required");
  }

  const meanX = data.reduce((sum, item) => sum + item.x, 0) / n;

  const meanY = data.reduce((sum, item) => sum + item.y, 0) / n;

  let covarianceSum = 0;
  let squaredX = 0;
  let squaredY = 0;

  for (const item of data) {
    const dx = item.x - meanX;
    const dy = item.y - meanY;

    covarianceSum += dx * dy;

    squaredX += dx * dx;
    squaredY += dy * dy;
  }

  // Population covariance
  const covariance = covarianceSum / n;

  // Population standard deviations
  const standardDeviationX = Math.sqrt(squaredX / n);
  const standardDeviationY = Math.sqrt(squaredY / n);

  // Pearson correlation
  const denominator = Math.sqrt(squaredX * squaredY);

  if (denominator === 0) {
    throw new Error("Pearson correlation is undefined");
  }

  const pearsonCorrelation = covarianceSum / denominator;

  return {
    observations: n,

    meanX,
    meanY,

    covariance,

    standardDeviationX,
    standardDeviationY,

    pearsonCorrelation,
  };
}

// Example dataset
const data: Observation[] = [
  { x: 1, y: 50 },
  { x: 2, y: 55 },
  { x: 3, y: 65 },
  { x: 4, y: 70 },
  { x: 5, y: 80 },
];

// Calculate statistics
const results = calculateBivariateStatistics(data);

console.log(results);
```

# 5\. Covariance vs. Pearson Correlation

It's important to understand the difference between these two concepts.

| Feature        | Covariance                             | Pearson Correlation                   |
| -------------- | -------------------------------------- | ------------------------------------- |
| Purpose        | Measures how variables change together | Measures linear relationship strength |
| Direction      | Positive or negative                   | Positive or negative                  |
| Range          | Unlimited                              | -1 to +1                              |
| Units          | Product of both variables' units       | No units                              |
| Standardized   | No                                     | Yes                                   |
| Interpretation | Magnitude depends on scale             | Easier to interpret                   |

### Key takeaway

Think about them this way:

- **Bivariate Data:** Two variables collected together.
- **Covariance:** Do the two variables move together?
- **Pearson Correlation:** How strong is their linear relationship?

For example, if you are analyzing hours studied and exam scores:

- Covariance tells you whether studying more tends to correspond to higher scores.
- Pearson correlation tells you how strongly those two variables are linearly related.

**Important:** Correlation does not imply causation. Even a correlation of 0.99 does not prove that studying alone caused the
higher exam scores.
