In statistics and machine learning, **classification** is the process of predicting which category or class an observation
belongs to.

While **regression** models predict a continuous numerical value (like a house price or temperature), **classification**
models predict a discrete label (like whether an email is "Spam" or "Not Spam," or whether a medical scan shows a tumor is
"Benign" or "Malignant").

---

### Types of Classification Problems

Depending on how many categories you are trying to predict, classification generally falls into two main buckets:

1. **Binary Classification:** There are only two possible outcomes.

- _Examples:_ Pass/Fail, Approved/Denied, Sick/Healthy, Email is Spam/Not Spam.

2. **Multiclass Classification:** There are three or more possible outcomes, but an observation can only belong to _one_ of
   them at a time.

- _Examples:_ Predicting a handwritten digit (0 through 9), classifying a weather type (Sunny, Rainy, Snowy, Cloudy), or
  identifying animal species.

---

### Common Classification Algorithms

Statisticians and data scientists use a variety of mathematical models to perform classification:

- **Logistic Regression:** Despite having "regression" in its name, this is actually a foundational classification algorithm.
  Instead of predicting a straight line, it uses a sigmoid function to output a probability between 0 and 1 (e.g., "There is
  an 85% chance this email is spam").
- **Decision Trees:** A flowchart-like model that splits data into branches based on feature thresholds (e.g., _Is income >
  $50k$?_ $\rightarrow$ Yes/No).
- **K-Nearest Neighbors (KNN):** Looks at the data points closest to a new observation and assigns it to the majority class
  among those neighbors.
- **Support Vector Machines (SVM):** Finds the optimal mathematical boundary (hyperplane) that best separates different
  classes in a multi-dimensional space.

---

### How Do We Evaluate a Classifier?

Instead of using error metrics like RMSE (which measure numerical distance), classification models are evaluated using
metrics derived from a **Confusion Matrix** (a table comparing predicted labels against actual true labels):

- **Accuracy:** The percentage of total predictions the model got right.
- **Precision:** When the model predicts the positive class, how often is it actually correct? (Minimizes false positives).
- **Recall (Sensitivity):** Out of all the actual positive cases in the data, how many did the model manage to catch?
  (Minimizes false negatives).
