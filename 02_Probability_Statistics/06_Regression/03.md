You can calculate **linear regression in TypeScript** using the least squares method.

Linear regression finds the best-fitting straight line through a set of data points.

The equation is:

$$
\hat{y} = b_0 + b_1x
$$

Where:

- $b_0$ = Y-intercept.
- $b_1$ = Slope.
- $x$ = Independent variable.
- $\hat{y}$ = Predicted value.

## 1\. TypeScript implementation

Here's a simple implementation without external libraries:

typescript

```typescript
interface Point {
  x: number;
  y: number;
}

interface RegressionResult {
  slope: number;
  intercept: number;
  predict: (x: number) => number;
}

function linearRegression(points: Point[]): RegressionResult {
  const n = points.length;

  if (n < 2) {
    throw new Error("At least two points are required");
  }

  const sumX = points.reduce((sum, p) => sum + p.x, 0);
  const sumY = points.reduce((sum, p) => sum + p.y, 0);

  const sumXY = points.reduce((sum, p) => sum + p.x * p.y, 0);
  const sumXX = points.reduce((sum, p) => sum + p.x * p.x, 0);

  const denominator = n * sumXX - sumX * sumX;

  if (denominator === 0) {
    throw new Error("Cannot calculate regression: all X values are equal");
  }

  const slope = (n * sumXY - sumX * sumY) / denominator;

  const intercept = (sumY - slope * sumX) / n;

  return {
    slope,
    intercept,
    predict: (x: number) => intercept + slope * x,
  };
}
```

## 2\. Example usage

Let's say you have the following data:

typescript

```typescript
const points: Point[] = [
  { x: 1, y: 2 },
  { x: 2, y: 3 },
  { x: 3, y: 5 },
  { x: 4, y: 4 },
  { x: 5, y: 6 },
];

const regression = linearRegression(points);

console.log("Slope:", regression.slope);
console.log("Intercept:", regression.intercept);

console.log("Prediction for x=6:", regression.predict(6));
```

Expected output:

text

```text
Slope: 0.9
Intercept: 1.3
Prediction for x=6: 6.7
```

## 3\. Visual explanation

y^=b0+b1x\\hat{y} = b_0 + b_1x

The algorithm finds the line that minimizes the sum of squared vertical distances (residuals) between the actual data points
and predicted values.

## 4\. Understanding the result

For our example, the regression equation is:

$$
\hat{y} = 1.3 + 0.9x
$$

This means:

- Every time X increases by 1, predicted Y increases by 0.9.
- When X is 0, predicted Y is 1.3.
- For X = 6, predicted Y is 6.7.

**One important distinction:** This implementation performs simple linear regression (one independent variable). If you need
multiple independent variables, you'd want multiple linear regression, typically implemented using matrices and linear
algebra.
