The **Chi-squared ($\chi^2$) test** is a statistical tool used to determine whether there is a significant difference between
expected frequencies and the observed frequencies in one or more categories.

You use a Chi-squared test when your data consists of **counts or frequencies of categorical variables** (rather than
continuous numerical measurements like height or weight).

---

### Main Types of Chi-Squared Tests & Where to Use Them

#### 1. Chi-Squared Test of Independence (Most Common)

- **What it does:** Tests whether two categorical variables are related or independent of each other.
- **Where to use it:**
- **Marketing/Business:** Determining if customer satisfaction (e.g., Satisfied, Neutral, Dissatisfied) is dependent on the
  store location (e.g., North, South, East).
- **Medicine/Biology:** Testing whether a new drug treatment (Treatment vs. Placebo) is associated with recovery outcome
  (Recovered vs. Did not recover).
- **Social Science:** Checking if voting preference (Party A, Party B) is associated with age group (18–30, 31–50, 51+).

#### 2. Chi-Squared Goodness-of-Fit Test

- **What it does:** Tests whether a sample of data matches a known or expected theoretical distribution.
- **Where to use it:**
- **Genetics:** Testing Mendelian inheritance ratios (e.g., checking if pea plant offspring ratios match the expected 3:1
  dominant-to-recessive ratio).
- **Quality Control:** Checking if a die or a roulette wheel is fair by seeing if the frequency of each number rolled matches
  an expected uniform probability ($\frac{1}{6}$ for each side).

---

### Key Requirements for Using Chi-Squared

Before running a Chi-squared test, make sure your data meets these conditions:

- **Categorical Data:** The variables must be categories (nominal or ordinal), not continuous numbers.
- **Independent Observations:** Each subject or data point can only belong to one cell in the table (no double-counting).
- **Sample Size:** The expected frequency in each category should generally be at least 5 to ensure reliable results.
