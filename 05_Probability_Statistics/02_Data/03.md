A **Dual Axis Chart** in Python is a chart that displays two different datasets with two different Y-axes but a shared
X-axis.

It is useful when you want to compare two variables that have different units or scales.

For example:

- Monthly Sales (in dollars)
- Profit Percentage (in %)

You can create a dual-axis chart using **Matplotlib's\*\***`twinx()`\***\*function**.

## 1\. Create a Dual Axis Line Chart

**Example: Monthly Sales vs Profit Percentage**

python

```python
import matplotlib.pyplot as plt

# Data
months = ['Jan', 'Feb', 'Mar', 'Apr', 'May']
sales = [1000, 1500, 1200, 2000, 2500]
profit = [10, 15, 12, 18, 25]

# Create figure and first axis
fig, ax1 = plt.subplots()

# First Y-axis (Sales)
ax1.plot(months, sales, color='blue', marker='o')
ax1.set_xlabel('Months')
ax1.set_ylabel('Sales ($)', color='blue')

# Create second Y-axis
ax2 = ax1.twinx()

# Second Y-axis (Profit)
ax2.plot(months, profit, color='red', marker='s')
ax2.set_ylabel('Profit (%)', color='red')

# Add title
plt.title('Monthly Sales vs Profit')

# Display chart
plt.show()
```

### How does it work?

- `plt.subplots()` – Creates the figure and first axis.
- `ax1.plot()` – Creates the first line chart.
- `ax1.twinx()` – Creates a second Y-axis on the right side.
- `ax2.plot()` – Creates the second line chart.
- `ax1.set_ylabel()` – Sets the left Y-axis label.
- `ax2.set_ylabel()` – Sets the right Y-axis label.

## 2\. Create a Dual Axis Bar and Line Chart

This is one of the most commonly used charts in data analytics.

**Example: Sales vs Profit Margin**

python

```python
import matplotlib.pyplot as plt

# Data
months = ['Jan', 'Feb', 'Mar', 'Apr', 'May']
sales = [1000, 1500, 1200, 2000, 2500]
profit = [10, 15, 12, 18, 25]

# Create figure
fig, ax1 = plt.subplots()

# Bar chart for sales
ax1.bar(months, sales, color='skyblue', label='Sales')
ax1.set_xlabel('Months')
ax1.set_ylabel('Sales ($)', color='blue')

# Create second axis
ax2 = ax1.twinx()

# Line chart for profit
ax2.plot(months, profit, color='red',
         marker='o', linewidth=2, label='Profit %')

ax2.set_ylabel('Profit (%)', color='red')

# Add title
plt.title('Sales vs Profit Margin')

# Display chart
plt.show()
```

## 3\. Create a Dual Axis Chart with Legend

If you want both datasets to appear in a single legend, use:

python

```python
import matplotlib.pyplot as plt

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May']
sales = [1000, 1500, 1200, 2000, 2500]
profit = [10, 15, 12, 18, 25]

fig, ax1 = plt.subplots()

# First axis
line1 = ax1.bar(months, sales, color='skyblue',
                label='Sales')

ax1.set_xlabel('Months')
ax1.set_ylabel('Sales ($)')

# Second axis
ax2 = ax1.twinx()

line2, = ax2.plot(months, profit, color='red',
                  marker='o', label='Profit %')

ax2.set_ylabel('Profit (%)')

# Combine legends
ax1.legend([line1, line2], ['Sales', 'Profit %'],
           loc='upper left')

plt.title('Monthly Sales and Profit')
plt.show()
```

## 4\. Difference Between Normal and Dual Axis Charts

| Feature  | Normal Chart        | Dual Axis Chart        |
| -------- | ------------------- | ---------------------- |
| Y-axis   | One                 | Two                    |
| X-axis   | One                 | One shared             |
| Datasets | One or more         | Usually two            |
| Scale    | Shared Y-axis scale | Separate Y-axis scales |
| Function | `plt.plot()`        | `ax1.twinx()`          |

## 5\. Important Functions to Remember

| Function         | Purpose                  |
| ---------------- | ------------------------ |
| `plt.subplots()` | Creates figure and axis  |
| `ax1.plot()`     | Creates first line       |
| `ax1.bar()`      | Creates bar chart        |
| `ax1.twinx()`    | Creates second Y-axis    |
| `ax2.plot()`     | Creates second line      |
| `ax2.bar()`      | Creates second bar chart |
| `ax1.legend()`   | Adds legend              |
| `plt.show()`     | Displays chart           |

### 6\. When Should You Use Dual Axis Charts?

Some practical examples from data analytics:

1. Sales vs Profit Percentage.
2. Revenue vs Number of Orders.
3. Website Visitors vs Conversion Rate.
4. Temperature vs Rainfall.
5. Advertising Spend vs Sales Revenue.

**Interview Tip:** If someone asks you how to create a dual-axis chart in Python, remember this function:

python

```python
ax2 = ax1.twinx()
```

This is the key function in Matplotlib for creating a secondary Y-axis.

**One important point:** Dual-axis charts can sometimes be misleading because changing either axis scale can change how the
relationship looks. Always label both axes clearly and use different colors.
