You can create a **Cumulative Frequency Chart in Python** using Matplotlib.

A cumulative frequency chart (also called an **Ogive Curve**) shows the running total of frequencies up to a particular value
or class interval.

It helps you understand how many observations fall below or equal to a particular value.

Let's understand it step by step.

## 1\. Understand Cumulative Frequency

Suppose you have the following student marks:

| Marks  | Frequency | Cumulative Frequency |
| ------ | --------- | -------------------- |
| 0–20   | 5         | 5                    |
| 20–40  | 10        | 15                   |
| 40–60  | 15        | 30                   |
| 60–80  | 12        | 42                   |
| 80–100 | 8         | 50                   |

**Formula:**

Cumulative Frequency = Previous Cumulative Frequency + Current Frequency.

For example:

- First interval = 5
- Second interval = 5 + 10 = 15
- Third interval = 15 + 15 = 30
- Fourth interval = 30 + 12 = 42
- Fifth interval = 42 + 8 = 50

## 2\. Create a Cumulative Frequency Chart Using Matplotlib

python

```python
import matplotlib.pyplot as plt

# Data
marks = [20, 40, 60, 80, 100]
frequency = [5, 10, 15, 12, 8]

# Calculate cumulative frequency
cumulative_frequency = []

total = 0

for value in frequency:
    total = total + value
    cumulative_frequency.append(total)

# Create cumulative frequency chart
plt.plot(marks, cumulative_frequency,
         marker='o', color='blue')

# Add title and labels
plt.title('Cumulative Frequency Chart')
plt.xlabel('Marks')
plt.ylabel('Cumulative Frequency')

plt.grid(True)

plt.show()
```

Here:

- `plt.plot()` creates the line chart.
- `marker='o'` displays points.
- `cumulative_frequency` stores the running total.
- `plt.grid()` adds grid lines.

## 3\. Create a Cumulative Frequency Chart Using NumPy

You can also calculate cumulative frequency using NumPy's `cumsum()` function.

python

```python
import matplotlib.pyplot as plt
import numpy as np

# Data
marks = [20, 40, 60, 80, 100]
frequency = [5, 10, 15, 12, 8]

# Calculate cumulative frequency
cf = np.cumsum(frequency)

# Plot chart
plt.plot(marks, cf, marker='o',
         color='green', linewidth=2)

plt.title('Cumulative Frequency Distribution')
plt.xlabel('Marks')
plt.ylabel('Cumulative Frequency')

plt.grid(True)

plt.show()
```

**Important:** `np.cumsum()` calculates the cumulative sum of values.

For example:

python

```python
import numpy as np

frequency = [5, 10, 15, 12, 8]

print(np.cumsum(frequency))
```

Output:

text

```text
[ 5 15 30 42 50]
```

## 4\. Create a More Professional Cumulative Frequency Chart

python

```python
import matplotlib.pyplot as plt
import numpy as np

# Data
marks = [20, 40, 60, 80, 100]
frequency = [5, 10, 15, 12, 8]

# Cumulative frequency
cf = np.cumsum(frequency)

# Chart size
plt.figure(figsize=(8, 5))

# Plot
plt.plot(
    marks,
    cf,
    marker='o',
    color='red',
    linewidth=2,
    markersize=7
)

# Add titles
plt.title('Student Marks - Cumulative Frequency',
          fontsize=14)

plt.xlabel('Marks')
plt.ylabel('Cumulative Frequency')

# Add grid
plt.grid(axis='both', linestyle='--', alpha=0.5)

plt.show()
```

## 5\. Difference Between Frequency and Cumulative Frequency

| Feature     | Frequency                                       | Cumulative Frequency             |
| ----------- | ----------------------------------------------- | -------------------------------- |
| Meaning     | Number of observations in a particular interval | Running total of observations    |
| Calculation | Count of observations                           | Sum of frequencies               |
| Values      | Individual counts                               | Continuously increasing totals   |
| Chart       | Histogram                                       | Ogive curve                      |
| Purpose     | Understand frequency distribution               | Understand accumulated frequency |

## 7\. Interview Questions

**Q1. What is cumulative frequency?**

Cumulative frequency is the running total of frequencies up to a particular class interval.

**Q2. What is an Ogive Curve?**

An Ogive Curve is a graphical representation of cumulative frequency. It helps understand how observations accumulate across
different values.

**Q3. Which Python function is used to calculate cumulative frequency?**

python

```python
np.cumsum()
```

**Q4. What is the difference between frequency and cumulative frequency?**

Frequency represents the number of observations in a particular class, whereas cumulative frequency represents the total
number of observations up to that class.
