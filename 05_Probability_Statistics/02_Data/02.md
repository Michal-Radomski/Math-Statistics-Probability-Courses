You can create **Line Charts** and **Bar Charts** in Python using the `Matplotlib` library. It is one of the most popular
libraries for data visualization.

Let's learn both step by step with examples.

python

## 2\. Create a Line Chart

A line chart is used to show trends or changes over time.

**Example: Monthly sales**

python

```python
import matplotlib.pyplot as plt

# Data
months = ['Jan', 'Feb', 'Mar', 'Apr', 'May']
sales = [100, 150, 120, 200, 250]

# Create line chart
plt.plot(months, sales, marker='o', color='blue')

# Add title and labels
plt.title('Monthly Sales')
plt.xlabel('Months')
plt.ylabel('Sales')

# Display chart
plt.show()
```

**Important functions:**

- `plt.plot()` – Creates a line chart.
- `marker='o'` – Displays circular markers on data points.
- `color='blue'` – Sets the line color.
- `plt.title()` – Adds a chart title.
- `plt.xlabel()` – Adds an X-axis label.
- `plt.ylabel()` – Adds a Y-axis label.
- `plt.show()` – Displays the chart.

## 3\. Create a Bar Chart

A bar chart is used to compare values across different categories.

**Example: Student marks**

python

```python
import matplotlib.pyplot as plt

# Data
students = ['John', 'Alice', 'Bob', 'David', 'Emma']
marks = [85, 90, 75, 80, 95]

# Create bar chart
plt.bar(students, marks, color='green')

# Add title and labels
plt.title('Student Marks')
plt.xlabel('Students')
plt.ylabel('Marks')

# Display chart
plt.show()
```

**Important functions:**

- `plt.bar()` – Creates a vertical bar chart.
- `color='green'` – Sets the bar color.
- `plt.title()` – Adds a chart title.
- `plt.xlabel()` – Adds an X-axis label.
- `plt.ylabel()` – Adds a Y-axis label.

## 4\. Create a Horizontal Bar Chart

You can also create horizontal bars using `plt.barh()`.

python

```python
import matplotlib.pyplot as plt

products = ['Laptop', 'Mobile', 'Tablet', 'Watch']
sales = [200, 350, 150, 100]

plt.barh(products, sales, color='orange')

plt.title('Product Sales')
plt.xlabel('Sales')
plt.ylabel('Products')

plt.show()
```

## 5\. Difference Between Line Chart and Bar Chart

| Feature    | Line Chart           | Bar Chart          |
| ---------- | -------------------- | ------------------ |
| Function   | `plt.plot()`         | `plt.bar()`        |
| Purpose    | Show trends          | Compare categories |
| Appearance | Connected lines      | Rectangular bars   |
| Best for   | Time-based data      | Categorical data   |
| Example    | Monthly sales trends | Sales by product   |

## 6\. Bonus: Customize Your Charts

You can make your charts more attractive by adding grids, changing colors, and displaying values.

**Example: Bar chart with grid**

python

```python
import matplotlib.pyplot as plt

products = ['Laptop', 'Mobile', 'Tablet']
sales = [200, 350, 150]

plt.bar(products, sales, color='skyblue')

plt.title('Product Sales')
plt.xlabel('Products')
plt.ylabel('Sales')

plt.grid(axis='y', linestyle='--', alpha=0.5)

plt.show()
```
