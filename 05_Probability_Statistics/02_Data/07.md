You can create a **Box Plot (Box-and-Whisker Plot) in Python** using the `Matplotlib` library.

A box plot is used to understand the distribution of numerical data. It helps identify:

- Median
- Minimum value
- Maximum value (excluding outliers)
- First Quartile (Q1)
- Third Quartile (Q3)
- Outliers

It is especially useful in Data Analytics and Exploratory Data Analysis (EDA).

## 1\. Create a Simple Box Plot

**Example: Employee Salary Distribution**

python

```python
import matplotlib.pyplot as plt

# Employee salary data
salary = [25000, 30000, 35000, 40000, 45000,
          50000, 55000, 60000, 65000, 100000]

# Create box plot
plt.boxplot(salary)

# Add title and labels
plt.title('Employee Salary Distribution')
plt.ylabel('Salary')

# Display chart
plt.show()
```

## 2\. Create a Box Plot with Customization

You can customize the box plot using different parameters.

python

```python
import matplotlib.pyplot as plt

salary = [25000, 30000, 35000, 40000, 45000,
          50000, 55000, 60000, 65000, 100000]

plt.boxplot(
    salary,
    patch_artist=True,
    showmeans=True,
    boxprops=dict(facecolor='skyblue'),
    medianprops=dict(color='red'),
    whiskerprops=dict(color='black'),
    capprops=dict(color='green')
)

plt.title('Employee Salary Distribution')
plt.ylabel('Salary')

plt.show()
```

**Important parameters:**

- `patch_artist=True` – Fills the box with color.
- `showmeans=True` – Displays the mean value.
- `medianprops` – Customizes the median line.
- `boxprops` – Customizes the box.
- `whiskerprops` – Customizes whiskers.

## 3\. Create Multiple Box Plots

Suppose you want to compare salaries across three departments.

python

```python
import matplotlib.pyplot as plt

# Department-wise salary
IT = [30000, 35000, 40000, 45000, 50000]
HR = [25000, 28000, 32000, 35000, 40000]
Sales = [20000, 30000, 35000, 45000, 60000]

# Create multiple box plots
plt.boxplot([IT, HR, Sales])

plt.title('Department-wise Salary Distribution')
plt.xlabel('Department')
plt.ylabel('Salary')

plt.show()
```

This helps compare salary distributions across departments.

## 4\. Understand the Box Plot Structure

Here are the five important components:

| Component   | Meaning                   |
| ----------- | ------------------------- |
| Minimum     | Lowest non-outlier value  |
| Q1          | 25th percentile           |
| Median (Q2) | 50th percentile           |
| Q3          | 75th percentile           |
| Maximum     | Highest non-outlier value |

**Understanding the terms:**

- **Q1:** 25% of observations fall below this value.
- **Q2:** 50% of observations fall below this value.
- **Q3:** 75% of observations fall below this value.
- **IQR:** Interquartile Range = Q3 − Q1.

### What are Outliers?

Outliers are unusually high or low values compared with the rest of the dataset.

The common IQR method identifies potential outliers using:

- Lower limit = Q1 − 1.5 × IQR
- Upper limit = Q3 + 1.5 × IQR

Values outside these limits are considered potential outliers.

## 5\. Important Box Plot Functions

| Function/Parameter  | Purpose                     |
| ------------------- | --------------------------- |
| `plt.boxplot()`     | Creates a box plot          |
| `patch_artist=True` | Fills box with color        |
| `showmeans=True`    | Displays mean               |
| `showfliers=True`   | Displays outliers           |
| `vert=False`        | Creates horizontal box plot |
| `medianprops`       | Customizes median           |
| `boxprops`          | Customizes box              |
| `plt.title()`       | Adds chart title            |
| `plt.show()`        | Displays chart              |

## 6\. Difference Between Histogram and Box Plot

| Feature             | Histogram               | Box Plot                     |
| ------------------- | ----------------------- | ---------------------------- |
| Purpose             | Shows data distribution | Summarizes data distribution |
| Shows median        | No                      | Yes                          |
| Shows quartiles     | No                      | Yes                          |
| Identifies outliers | Not directly            | Yes                          |
| Shows frequency     | Yes                     | No                           |
| Python function     | `plt.hist()`            | `plt.boxplot()`              |

## 7\. When Should You Use a Box Plot?

In real-world Data Analytics projects, box plots are useful for:

1. Identifying outliers in employee salaries.
2. Comparing customer spending across different regions.
3. Comparing student marks across different classes.
4. Analyzing product delivery times.
5. Understanding the distribution of customer ages.

### Interview Questions

**Q1. What is a box plot?**

A box plot is a graphical representation of numerical data that displays the median, quartiles, spread and potential
outliers.

**Q2. What is IQR?**

IQR stands for Interquartile Range.

Formula:

`IQR = Q3 - Q1`

**Q3. How do you identify outliers using a box plot?**

Values below Q1 − 1.5 × IQR or above Q3 + 1.5 × IQR are considered potential outliers.

**Q4. What is the difference between mean and median?**

- Mean: Average of all observations.
- Median: Middle value when observations are arranged in ascending order.
