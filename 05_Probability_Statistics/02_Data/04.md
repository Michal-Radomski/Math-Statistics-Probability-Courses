You can create a **Pie Chart in Python** using the `Matplotlib` library.

A pie chart is used to show the percentage or proportion of different categories within a whole.

For example:

- Product-wise sales contribution.
- Department-wise expenses.
- Market share of different companies.
- Category-wise revenue.

## 1\. Create a Simple Pie Chart

**Example: Product-wise Sales**

python

```python
import matplotlib.pyplot as plt

# Data
products = ['Laptop', 'Mobile', 'Tablet', 'Watch']
sales = [40, 30, 20, 10]

# Create pie chart
plt.pie(sales, labels=products)

# Add title
plt.title('Product-wise Sales')

# Display chart
plt.show()
```

## 2\. Create a Pie Chart with Percentages

Use `autopct` to display percentages on the chart.

python

```python
import matplotlib.pyplot as plt

products = ['Laptop', 'Mobile', 'Tablet', 'Watch']
sales = [40, 30, 20, 10]

plt.pie(
    sales,
    labels=products,
    autopct='%1.1f%%'
)

plt.title('Product-wise Sales')

plt.show()
```

**Output percentages:**

- Laptop: 40%
- Mobile: 30%
- Tablet: 20%
- Watch: 10%

## 3\. Create a Pie Chart with Different Colors

Use the `colors` parameter to customize colors.

python

```python
import matplotlib.pyplot as plt

products = ['Laptop', 'Mobile', 'Tablet', 'Watch']
sales = [40, 30, 20, 10]

colors = ['skyblue', 'orange', 'green', 'red']

plt.pie(
    sales,
    labels=products,
    colors=colors,
    autopct='%1.1f%%'
)

plt.title('Product-wise Sales')

plt.show()
```

## 4\. Create an Exploded Pie Chart

An exploded pie chart highlights a particular category.

Use the `explode` parameter.

python

```python
import matplotlib.pyplot as plt

products = ['Laptop', 'Mobile', 'Tablet', 'Watch']
sales = [40, 30, 20, 10]

explode = (0.1, 0, 0, 0)

plt.pie(
    sales,
    labels=products,
    autopct='%1.1f%%',
    explode=explode,
    shadow=True
)

plt.title('Product-wise Sales')

plt.show()
```

Here:

- `explode=(0.1, 0, 0, 0)` separates the Laptop slice.
- `shadow=True` adds a shadow effect.

## 5\. Create a Professional Pie Chart

python

```python
import matplotlib.pyplot as plt

products = ['Laptop', 'Mobile', 'Tablet', 'Watch']
sales = [40, 30, 20, 10]

colors = ['#3498db', '#e67e22', '#2ecc71', '#e74c3c']

plt.figure(figsize=(8, 6))

plt.pie(
    sales,
    labels=products,
    autopct='%1.1f%%',
    startangle=90,
    colors=colors,
    explode=(0.05, 0, 0, 0),
    shadow=True,
    wedgeprops={'edgecolor': 'white'}
)

plt.title('Product-wise Sales Distribution', fontsize=15)

plt.show()
```

## 6\. Important Pie Chart Functions

| Function/Parameter | Purpose                      |
| ------------------ | ---------------------------- |
| `plt.pie()`        | Creates a pie chart          |
| `labels`           | Adds category names          |
| `autopct`          | Displays percentages         |
| `colors`           | Changes slice colors         |
| `explode`          | Separates a particular slice |
| `shadow`           | Adds shadow effect           |
| `startangle`       | Rotates the pie chart        |
| `wedgeprops`       | Customizes pie slices        |
| `plt.title()`      | Adds chart title             |
| `plt.show()`       | Displays the chart           |

## 7\. Difference Between Charts in Python

| Chart          | Function      | Purpose                      |
| -------------- | ------------- | ---------------------------- |
| Line Chart     | `plt.plot()`  | Show trends                  |
| Bar Chart      | `plt.bar()`   | Compare categories           |
| Horizontal Bar | `plt.barh()`  | Horizontal comparisons       |
| Pie Chart      | `plt.pie()`   | Show percentage contribution |
| Dual Axis      | `ax1.twinx()` | Compare different scales     |
