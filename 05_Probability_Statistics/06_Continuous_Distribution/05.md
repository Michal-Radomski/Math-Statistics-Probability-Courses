The **inverse normal distribution**—more formally known as the **quantile function** or **percent point function (PPF)**—does
the exact opposite of the Cumulative Distribution Function (CDF).

- **CDF:** Given a score ($x$), find the **probability**. _(e.g., "What percentage of students scored below 115?")_
- **Inverse CDF (PPF):** Given a probability or percentile ($p$), find the **score** ($x$). _(e.g., "What score do you need
  to be in the 90th percentile?")_

---

## How It Works Visually

If the CDF takes an area under the bell curve (from left to right) and outputs a probability between $0$ and $1$, the inverse
function takes that area fraction and returns the exact cutoff value on the horizontal axis ($x$).

---

## Python Examples

### Option 1: Using Python's Built-in `statistics` Module (Python 3.8+)

```python
from statistics import NormalDist

# IQ scores: Mean = 100, Standard Deviation = 15
iq_dist = NormalDist(mu=100, sigma=15)

# What IQ score corresponds to the 90th percentile (probability = 0.90)?
score = iq_dist.inv_cdf(0.90)
print(f"90th Percentile IQ Score: {score:.2f}")  # ~119.22

```

### Option 2: Using SciPy (`scipy.stats`)

```python
from scipy.stats import norm

mu, sigma = 100, 15

# Find the value for the 90th percentile using PPF (Percent Point Function)
score = norm.ppf(0.90, loc=mu, scale=sigma)
print(f"90th Percentile IQ Score: {score:.2f}")  # ~119.22

```

---

## JavaScript / TypeScript Implementation Note

Just like standard JavaScript lacks a native `Math.erf()`, it also lacks a native inverse error function (`Math.erfinv`). To
compute inverse normal distributions natively in JS/TS, developers typically implement a rational approximation algorithm
(such as the Wichura or Beasley-Springer-Moro algorithm) or use math libraries like **Math.js**.
