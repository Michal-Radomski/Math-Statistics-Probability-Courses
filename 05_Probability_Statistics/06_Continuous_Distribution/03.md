# Calculating Probabilities with the Normal Distribution (Python / JavaScript / TypeScript)

The **normal distribution** is a continuous probability distribution characterized by:

- **Mean (μ):** The average value.
- **Standard deviation (σ):** How spread out the values are.
- **x:** The value or threshold we want to calculate probabilities for.

## 1\. Mathematical formula

To calculate probabilities, we first convert a value into a **Z-score**:

z=x−μσz = \\frac{x - \\mu}{\\sigma}

The Z-score tells us how many standard deviations a value is from the mean.

We then use the standard normal cumulative distribution function (CDF):

$$
P(X \leq x) = \Phi(z)
$$

## 2\. Python implementation

Python provides an easy way to calculate normal distribution probabilities using SciPy.

python

```python
from scipy.stats import norm

# Distribution parameters
mean = 100
std_dev = 15

# Value we want to calculate
x = 120

# Probability that X <= 120
p_less = norm.cdf(x, mean, std_dev)

# Probability that X > 120
p_greater = 1 - norm.cdf(x, mean, std_dev)

# Probability that 90 < X < 120
p_between = (
    norm.cdf(120, mean, std_dev)
    - norm.cdf(90, mean, std_dev)
)

print("P(X <= 120):", p_less)
print("P(X > 120):", p_greater)
print("P(90 < X < 120):", p_between)
```

## 3\. JavaScript / TypeScript implementation

JavaScript doesn't have a built-in normal distribution function, but we can implement the normal CDF.

javascript

```javascript
function erf(x) {
  const sign = x >= 0 ? 1 : -1;
  x = Math.abs(x);

  const a1 = 0.254829592;
  const a2 = -0.284496736;
  const a3 = 1.421413741;
  const a4 = -1.453152027;
  const a5 = 1.061405429;
  const p = 0.3275911;

  const t = 1 / (1 + p * x);

  const y = 1 - ((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t * Math.exp(-x * x);

  return sign * y;
}

function normalCDF(x, mean, stdDev) {
  if (stdDev <= 0) {
    throw new Error("Standard deviation must be positive");
  }

  const z = (x - mean) / (stdDev * Math.sqrt(2));

  return 0.5 * (1 + erf(z));
}

// Distribution parameters
const mean = 100;
const stdDev = 15;

// Calculate probabilities
const pLess = normalCDF(120, mean, stdDev);

const pGreater = 1 - normalCDF(120, mean, stdDev);

const pBetween = normalCDF(120, mean, stdDev) - normalCDF(90, mean, stdDev);

console.log("P(X <= 120):", pLess);
console.log("P(X > 120):", pGreater);
console.log("P(90 < X < 120):", pBetween);
```

_Note: This JavaScript implementation uses an approximation of the error function._

## 4\. Common probability calculations

| Probability     | Formula                        |
| --------------- | ------------------------------ |
| Less than x     | $P(X < x)=\Phi(z)$             |
| Greater than x  | $P(X > x)=1-\Phi(z)$           |
| Between a and b | $P(a<X<b)=\Phi(z_b)-\Phi(z_a)$ |
| Outside a and b | $P(X<a)+P(X>b)$                |

## 5\. Example

Suppose exam scores follow a normal distribution:

- Mean: 70
- Standard deviation: 10

Calculate the probability that a randomly selected student scores above 85.

**Step 1: Calculate the Z-score.**

$$
z=\frac{85-70}{10}=1.5
$$

**Step 2: Calculate the probability.**

$$
P(X>85)=1-\Phi(1.5)
$$

$$
P(X>85)=1-0.9332
$$

$$
\boxed{P(X>85)=0.0668=6.68\%}
$$

Therefore, approximately **6.68% of students score above 85**.
