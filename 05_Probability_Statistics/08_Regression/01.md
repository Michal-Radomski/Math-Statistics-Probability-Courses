In statistics, **regression analysis** is a powerful method used to examine the relationship between a **dependent variable**
(what you want to predict or explain) and one or more **independent variables** (the predictors or causes).

While a t-test compares differences between groups, regression looks at how changes in one variable are associated with
changes in another.

---

### What is it Used For?

Regression is primarily used for two main purposes:

1. **Prediction and Forecasting:** Estimating a value based on other data (e.g., predicting a house's price based on its
   square footage and number of bedrooms).
2. **Understanding Relationships:** Figuring out _how much_ impact an independent variable has on a dependent variable (e.g.,
   how much each additional hour of studying increases an exam score).

---

### The Main Types of Regression

- **Simple Linear Regression:** Involves just one independent variable ($x$) and one dependent variable ($y$). It fits a
  straight "line of best fit" through data points using an equation like $y = mx + b$ (or $y = \beta_0 + \beta_1x$).
- **Multiple Linear Regression:** Involves one dependent variable and _two or more_ independent variables (e.g., predicting
  house prices using square footage, age of the house, and neighborhood safety score combined).
- **Non-Linear Regression:** Used when the relationship between variables isn't a straight line, but rather a curve or
  exponential pattern.

---

### How the "Line of Best Fit" Works

In linear regression, the goal is to draw a line through a scatter plot that minimizes the overall distance between the
actual data points and the line itself. This is typically calculated using a method called **Ordinary Least Squares (OLS)**,
which squares the distances (residuals) so that larger errors are penalized more heavily.
