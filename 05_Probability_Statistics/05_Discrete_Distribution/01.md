A **discrete probability distribution** is a statistical concept that describes all the possible values a random variable can
take, along with their corresponding probabilities, where the set of possible outcomes is **countable** (distinct, separate
values like 0, 1, 2, 3) rather than a continuous range.

### Key Characteristics

- **Distinct Outcomes:** The variable can only take specific, isolated values (e.g., you can roll a 3 or a 4 on a die, but
  not $3.5$).
- **Probabilities Sum to 1:** The sum of the probabilities for all possible outcomes in the distribution must always equal
  $1$ (or $100\%$).
- **Individual Probability Bounds:** The probability of any single outcome must be a number between $0$ and $1$ (inclusive),
  expressed mathematically as $0 \le P(X = x) \le 1$.

---

### Common Examples

1. **Rolling a Die:** When you roll a fair six-sided die, the possible outcomes are $1, 2, 3, 4, 5,$ and $6$. Each outcome
   has an equal discrete probability of $\frac{1}{6}$.
2. **Flipping Coins:** The number of heads you get when flipping a coin 3 times can only be $0, 1, 2,$ or $3$.
3. **Binomial Distribution:** A common type of discrete distribution used when there are two possible outcomes (like
   success/failure or yes/no) over a fixed number of trials.
4. **Poisson Distribution:** Used to model the number of times an event happens in a specified time period (e.g., the number
   of emails you receive in an hour).
