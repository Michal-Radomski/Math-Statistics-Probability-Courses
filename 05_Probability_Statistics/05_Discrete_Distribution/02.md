The **expected value** (or simply the **expectation**) of a discrete random variable, denoted as $E(X)$ or $\mu$, represents
the long-term theoretical average outcome of a random variable if you were to repeat an experiment a very large number of
times.

It is not necessarily a single value you will ever actually observe in a single trial; rather, it is a weighted average where
each possible outcome is weighted by its respective probability.

---

### The Formula

For a discrete random variable $X$ that takes on possible values $x_1, x_2, x_3, \dots$ with probabilities
$P(X = x_1), P(X = x_2), \dots$, the expected value is calculated as:

$$E(X) = \sum x \cdot P(X = x)$$

In plain English: **Multiply each possible outcome by its probability, then add all those products together.**

---

### Step-by-Step Example: A Simple Game

Imagine a carnival game where you draw a card from a standard deck or play a simplified dice game:

- You roll a fair six-sided die.
- If you roll a **6**, you win $\$6$.
- If you roll a **4 or 5**, you win $\$2$.
- If you roll a **1, 2, or 3**, you lose $\$1$ (which means a payoff of $-\$1$).

What is your expected payout per game?

#### 1. Identify the values ($x$) and their probabilities $P(X = x)$:

- $x_1 = \$6$, $P(X = 6) = \frac{1}{6}$
- $x_2 = \$2$, $P(X = 2) = \frac{2}{6} = \frac{1}{3}$
- $x_3 = -\$1$, $P(X = -1) = \frac{3}{6} = \frac{1}{2}$

#### 2. Set up the calculation:

| Outcome ($x$) | Probability $P(X = x)$ | $x \cdot P(X = x)$                  |
| ------------- | ---------------------- | ----------------------------------- |
| $\$6$         | $\frac{1}{6}$          | $6 \times \frac{1}{6} = 1.00$       |
| $\$2$         | $\frac{2}{6}$          | $2 \times \frac{2}{6} \approx 0.67$ |
| $-\$1$        | $\frac{3}{6}$          | $-1 \times \frac{3}{6} = -0.50$     |

#### 3. Sum the products:

$$E(X) = 1.00 + 0.67 + (-0.50) = \$1.17$$

**Interpretation:** On average, you can expect to win about **$\$1.17$** per game over the long run.

---

### Key Properties of Expectation

- **Linearity:** $E(aX + b) = aE(X) + b$ (where $a$ and $b$ are constants). Scaling a random variable scales its expectation
  by the same factor.
- **Additivity:** For any two random variables $X$ and $Y$ (even if they are dependent), $E(X + Y) = E(X) + E(Y)$.
